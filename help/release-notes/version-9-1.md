# 版本9.1

<b>Substance 3D Painter 9.1</b>为“路径”工具添加了切线控件、对SVG文件格式的支持、通过拖放导入和应用资源的功能以及在视口中支持半透明。

发行日期： *7 2023年11月*

## 主要功能

### 新的切线控件和路径工具的改进

![横幅路径工具](../assets/v91_banner_tangents.jpg)

在此新版本中，我们继续开发路径工具（在9.0版中引入），以添加社区要求的缺失位和功能。

* <b>手动控制路径点相切</b>

  现在可以手动设置路径上特定点的切线。 这可以覆盖自动行为以创建新形状。

  ![自定切线](../assets/path_control_tangents.gif)
* <b>通过机械手编辑路径点</b>

  有时，仅滑动对象表面的点是不够的。 操作器允许将点移动到曲面之外。 如果网格重新导入后距离曲面太远，一次移动多个点会非常有用。

  ![路径切线转换操纵器](../assets/path_tangents_translate.gif)
* <b>单独切换路径可见性</b>

  现在可以通过专用视口面板为每个路径更改路径可见性。 禁用路径将从最终纹理中移除其影响，而无需将其删除。

  ![路径面板可见性](../assets/path_panel_visibility.png)
* <b>复制和粘贴路径位置和属性</b>

  复制和粘贴路径已扩展为只能复制路径点位置或其属性。 现在可以按不同方式同步路径，从而更轻松地创建复杂效果（通过位置）或跨不同位置共享特定外观（通过属性）。

  ![显示如何复制和粘贴路径属性的Gif](../assets/path_copy_paste_properties.gif)

  ![显示如何复制和粘贴路径位置的Gif](../assets/path_copy_paste_vertices.gif)

>[!NOTE]
>
> 有关路径工具的更多信息，请参阅[专用文档](../painting/tool-list/path.md)。

### 新支持视区的半透明、透明度和吸收

![横幅ASM](../assets/v91_banner_asm.jpg)

<b>Adobe标准材质</b> (ASM)着色器（创建新项目时的默认着色器）已更新，以支持<b>半透明</b>、<b>透明</b>和<b>吸收</b>属性。 这意味着现在可以在实时视口中（以及在Iray渲染器中）查看这些渲染行为的结果。

因此，现在可以在视窗中直接查看具有细吸收光的创作材料，例如<b>玻璃</b>、<b>叶子</b>或<b>塑料</b>。 由于ASM定义，导出到其他Substance 3D应用程序也会导致匹配的外观。

* <b>新的ASM着色器设置</b>

  已更新ASM着色器以支持新功能，可以通过[着色器设置](../interface/shader-settings/shader-settings.md)窗口修改这些功能：

  * <b>透明度</b>（不透明度）：是否不再需要切换到其他着色器以获得透明表面（如叶子）。 而是应在<b>几何>不透明度</b>组下启用<b>alpha测试</b>或<b>alpha混合</b>参数。 也可以使用常规设置，例如抖动。
  * <b>半透明</b>：此新属性允许创建玻璃等表面，使形状透明，同时保持Specular反射。 要使用它，请在项目中添加半透明通道，并在<b>内部</b>组下启用<b>半透明</b>参数。
  * <b>吸收</b>：此新属性允许模拟光线通过对象并被吸收，这可用于以比使用次表面散射更好的方式模拟塑料或液体。 要使用它，请在<b>内部</b>组下启用<b>吸收</b>设置。
* <b>改进了着色器设置UI和工具提示</b>

  通过着色器的重新处理，我们借此机会改进了参数的UI，并添加了许多新的工具提示，以更轻松地了解如何激活它们。

  参数的顺序还应与其他Substance 3D软件更匹配，以便在试用设置时更易于来回操作。

  ![ASM工具提示](../assets/v91_asm_tooltips.png)
* <b>用于演示Adobe标准素材的新示例项目</b>

  一开始可能很难处理新的ASM属性，因此添加了一个新的示例项目，用于演示着色器的几个功能，以便更容易地学习这些功能。

  此项目名为<b>French Restaurant Table</b>，可通过<b>文件>打开示例</b>菜单找到。 它还可以使用很多小技巧，因此可以成为一个很好的学习资源来发现新的纹理创建方法。

  ![演示示例项目](../assets/v91_asm_demo_project.png)
* <b>半透明通道现在默认为黑色</b>

  为使新的着色器属性更易于使用并避免在视区中出现意外结果，已将通道半透明的默认颜色更改为黑色（而不是白色）。

  如果此通道已在项目中使用，则只需在图层栈叠底部添加填充图层并将通道值设置为白色，即可获得以前的行为。 您可能需要启用着色器参数中的<b>使用半透明作为散射蒙版</b>设置，以及重新应用通道对子表面散射结果的贡献。

### 矢量图形文件(SVG)的全新支持

![横幅SVG](../assets/v91_banner_svg.jpg)

此版本添加了SVG文件的支持，作为可用于图层、绘画工具等的资源。

SVG文件非常适用于精确地表示徽标或形状，同时重量非常轻。 在Painter中，它们可以按所需分辨率进行渲染并轻松更新，使其成为非破坏性工作流程的理想选择。

* <b>导入SVG文件</b>\
  SVG文件可以像导入任何其他资源一样导入到项目中、库中，等等。可以导入SVG<b>，最高版本为1.1</b>，不支持来自新版本的功能。

  在此版本中，导入也变得更加容易（请参阅下文），因此只需从Painter外部将资源直接拖放到网格或图层栈叠上，即可使用SVG文件。
* <b>专用SVG设置</b>\
  使用SVG资源时，有一些设置可用于控制其外观：

  * <b>分辨率</b>：使用自动分辨率、在文件中定义的分辨率或自定义值。
  * <b>裁剪区域</b>：定义要使用的SVG画布的特定区域。
  * <b>范围</b>：选择SVG的整个内容或仅选择某些元素。

  ![SVG设置](../assets/v91_svg_settings.png)
* <b>新SVG定制材料</b>

  添加了3个新资源，以帮助在添加纹理时使用SVG文件：

  * <b>自定义喷漆</b>：允许模拟从单个输入图像绘制在墙上的贴花。
  * <b>自定义贴纸</b>：在表面创建塑料贴纸。 它具有多种设置以模拟损坏和折叠。
  * <b>图形到材质</b>：允许通过单个图像输入创建多个材质属性。 将SVG文件拖放到视区中时，会自动插入此资源。 此资源提供了一种跨多个渠道共享其输入透明度的简单方法，使其非常适合简单的贴花。

  ![SVG资源图标](../assets/v91_svg_resources.png)

  ![图形到素材演示](../assets/v91_graphic_to_material_demo.png)

>[!NOTE]
>
> 有关SVG格式和设置的详细信息，请参阅[专用文档](../painting/vector-graphic-svg.md)。

### 通过拖放新建资源导入

![横幅导入拖放](../assets/v91_banner_drag_import.jpg)

此版本允许将外部文件拖放到应用程序的不同上下文中以自动导入并使用资源。 这个新流程允许跳过与导入文件相关的繁琐步骤。

* <b>通过拖放到视口导入</b>

  将外部文件拖到视口中，以便能够将其直接放在网格上。 此操作将自动创建新图层。 根据资源的性质（图像、Substance素材、Substance筛选等） 结果将相应调整。
* <b>通过拖放到图层栈栈中的方式导入</b>\
  与将外部资源文件拖放到视口的方法相同，将文件拖放到图层栈栈允许直接创建图层或效果，其中含有资源。
* <b>通过拖放到资源插槽中导入</b>

  也可以将资源直接导入图层或工具。 如果已存在使用正确设置的填充图层或效果，只需将外部文件拖放到“属性”窗口的某个通道槽中即可导入并应用它。

>[!NOTE]
>
> 有关导入资源的详细信息，[请参阅专用文档](../content/importing-assets/import-drag-and-drop.md)。

### 新资源拖放行为

![横幅拖放](../assets/v91_banner_drag_resources.jpg)

拖放改进不仅限于导入资源。 现在可使用从“资源”窗口拖放资源来动态创建新图层、效果甚至蒙版。

* <b>拖放多种类型的资源</b>

  现在可以将类型的资源直接拖放到视区或图层栈叠中。 以下类型的资源现在可以（几乎）在任何地方拖放：

  * Alpha
  * 纹理
  * 程序
  * 材质
  * 智能材质
  * 智能蒙版
  * 生成器
  * 滤镜
  * 环境地图
* <b>将资源作为新图层或效果删除</b>

  通过选择放置资源的位置，Painter将自动创建新图层或新效果：

  ![在图层栈栈中拖放](../assets/v91_drop_filter_stack.gif)
* <b>拖动时选择内容或蒙版效果栈栈\
  </b>

  将资源拖动到缩览图上时，Painter将自动切换到关联的效果栈栈。 之后，很容易就能将资源放在该栈栈内的精确位置。 这样可以避免预先切换到右侧栈栈。

  ![效果栈栈开关](../assets/v91_drop_stack_switch.gif)
* <b>动态创建新黑色蒙版</b>

  拖动资源时，新图标会出现在任何没有蒙版的图层上。 当资源被拖放到此Ghost掩码上时，它将自动创建一个新掩码并添加新资源。 这是一种快速设置新蒙版的方法，可以避免取消拖放操作来手动添加蒙版。

  ![拖放以创建新蒙版](../assets/v91_drop_new_mask.gif)
* <b>放入视区以创建新图层</b>

  还可以在视区中拖放资源以创建新图层。 根据资源的类型，结果可能会发生变化。 滤镜将在直通模式下创建绘画图层，而智能蒙版将创建新蒙版的填充图层。

  ![拖放智能蒙版](../assets/v91_drop_smart_mask.gif)

  ![拖放滤镜](../assets/v91_drop_filter.gif)
* <b>对高级行为使用键盘修饰符</b>

  删除资源时，保持键盘修改键CTRL或ALT可以启用其他行为：

  * <b>CTRL</b>放入<b>图层栈栈</b>时：使用黑色蒙版中的资源创建新图层。 对于强制将素材放入蒙版等操作很有用。 或者跳过带有Alpha字符的下拉菜单。
  * 在<b>图层栈栈</b>中放置时按<b>ALT</b>：仅在放置到图层缩览图上时适用。 按ALT键将删除以前的所有效果。 这可以作为一种快速试用不同资源（特别是智能蒙版）的方法，而无需先手动移除它们。
  * <b>CTRL</b>放入<b>视口</b>时：用黑色蒙版中的资源创建新图层。 资源将置于<b>颜色ID选择</b>效果下，此效果将根据在视区中完成的选择进行设置。
  * <b>ALT</b>放入<b>视口</b>时：与之前相同，将强制资源处于贴花投影模式。

### 其他改进

![横幅杂项](../assets/v91_banner_misc.jpg)

此版本中还添加了几项次要功能和改进。

* <b>16位图像的无损压缩</b>

  从现在起，项目中包含的位深度为16的任何图像都将采用无损算法压缩，从而可以在不损失质量的情况下减小图像大小。 另外，项目文件已压缩自己的数据。

  此更改主要针对<b>烘焙纹理</b>，这通常是项目文件在磁盘上可能很重的原因。 平均而言，我们看到项目<b>在磁盘</b>上的大小减少了30%到50%。

  在尚未压缩的资源上保存任何项目（旧项目或新项目）时，会自动应用此压缩。 这意味着，对于旧项目，在此新版本中首次保存可能需要比平时多一点时间。 完成此操作后，节省时间应恢复正常。
* <b>新的UV设置为UV设置填充投影模式</b>

  为填充图层/效果添加了一个新的投影模式，名为<b>UV集到UV集投影</b>。 它可用于基于项目内网格上可用的不同UV投影纹理。 它不需要依赖外部工具就可以执行更高级的纹理传输。

  <b>UV集0</b>是Painter用于绘画的默认UV。 如果有其他UV集可用，则可在设置<b>源</b>的下拉列表中找到它们：

  ![UV集投影](../assets/v91_uv_set_proj.png)
* 默认情况下，<b>在任何新项目上启用随机采样抗锯齿</b>

  创建新项目时，“显示设置”窗口中可用的<b>随机采样抗锯齿</b>设置现在默认启用，以提高视区中渲染的质量。
* <b>新的Python API改进</b>

  Python API在此版本中收到了一些新增功能：

  * 可使用新的<b>substance\_painter.application.close() </b>函数通过Python关闭/关闭Painter。
  * 现在可以通过API修改主视口摄像机。 这包括它的位置、旋转以及其他属性，如视场、光圈等。为了便于根据网格位置调整摄像机，API现在还显示场景定界框。
  * 现在可以通过导出模块导出项目网格（无论是否使用三角剖分和位移）。
  * 现在还可以从API检索项目导出纹理路径。
* <b>发送到After Effects (Beta)的新功能</b>

  现在，您可以利用新的发送到“动作”将网格及其纹理导出到After Effects，以便更方便地迭代视觉效果。 此功能需要访问至少After Effects 24.1 Beta版。
