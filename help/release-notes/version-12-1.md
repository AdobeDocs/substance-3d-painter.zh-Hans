# 版本 12.1

<b>Substance 3D Painter 12.1</b>改进了包含自动烘焙和倾斜校正绘画的烘焙工作流程，支持OpenPBR材料定义，并为自动UV展开提供了新的硬表面模式。

发行日期：<b>2026年6月22日</b>

>[!NOTE]
>
> 此版本将支持的最低macOS版本提高到13.0 (Ventura)。 有关详细信息，请查看我们的[系统要求页面](../getting-started/system-requirements.md)。

## 主要功能

### 改进的倾斜绘画烘焙工作流程

![](../assets/v12/v12_banner_skew.jpg)

烘焙工作流程经过重新设计，以支持连续重新生成、在网格上绘制倾斜校正、边缘保护以及重新设计的网格图列表。

* <b>自动重新生成</b>

  当网格图的烘焙参数被调整时，可以连续地重新烘焙，消除每次更改后手动触发烘焙的需要。 为每个地图切换自动重新生成，并一次应用于一个地图。 这对于倾斜绘画工作流程尤其方便，而且在调整常规烘焙设置时也是如此。

  ![](../assets/v12/v12_auto_rebake.png)

* <b>倾斜校正绘画</b>

  当笼子设置为<b>基于距离</b>模式时，可以将倾斜校正直接绘制在低多边形网格上，以控制烘焙期间使用的投影方向。 画笔、橡皮擦和多边形填充工具可用，带有一个紧凑的灰度值选取器、对称和常用画笔控件（<b>Ctrl +右键单击</b>调整画笔大小，<b>X</b>反转绘制值）。 倾斜绘画操作可以撤消。

  ![](../assets/v12/v12_skew_fix_rebake.gif)

* <b>边缘保护</b>

  当绘画倾斜校正时，新的边缘保护选项会保留投影到硬边缘上的高多边形柔和度。 其结果受<b>边缘距离</b>和<b>边缘对比度</b>参数控制。

  ![](../assets/v12/v12_skew_edge_distance.gif)

* <b>重新设计的网格图列表</b>

  网格图列表提供了按映射的控件：将映射切换为视口<b>预览</b>、<b>快速烘焙</b>单个映射、切换其<b>自动重新生成</b>以及跨纹理集<b>同步</b>其设置（当项目具有多个纹理集时可用）。 悬停时，每个控件都有一个工具提示。

  ![](../assets/v12/v12_quick_bake.png)

* <b>简化烘焙按钮</b>

  “烘焙”按钮已替换为显示要烘焙的映射数（纹理集xUV 平铺x所选网格图）的单个<b>烘焙</b>按钮。

  ![](../assets/v12/v12_bake_button.png)

>[!NOTE]
>
> 有关烘焙的更多信息，请参阅[专用文档页面](../baking/baking.md)。

### OpenPBR 支持

![](../assets/v12/v12_banner_openpbr.jpg)

Painter现在支持OpenPBR着色模型，并将其用作默认工作流程，从而提供可在应用程序间执行的标准化材料定义。

* <b>新着色器和默认工作流程</b>

  默认情况下，可以使用一种实现OpenPBR1.1规范的着色器。 无模板创建的新项目使用着色器，新项目窗口的第一个条目现在标记为<b>OpenPBR</b>而不是<b>ASM</b>。 其中包括了用于OpenPBR的新项目模板，并且已更新示例项目以使用它。

  ![](../assets/v12/v12_openpbr_shader_icon.jpg)

* 导入时从项目模板中选择了<b>个着色器</b>

  导入USD或GLTF文件时，现在将从项目模板设置着色器，而不是从文件内容猜测值。 当材料和模板使用不匹配的工作流时，将在日志中报告一条消息。

  ![](../assets/v12/v12_openpbr_template.png)

* <b>导出的OpenPBR命名约定</b>

  <b>导出纹理</b>窗口中有一个新的下拉列表，用于选择命名约定。 当项目中至少有一个着色器使用它时，它默认为OpenPBR，并且所选方案会反映在每个纹理集的地图列表中。

  ![](../assets/v12/v12_openpbr_export.png)

* <b>USD和MDL支持</b>

  USD格式支持OpenPBR材料。 还添加了一个新的MDL，以允许在Iray中渲染OpenPBR材料，从而提供更准确的材料表示形式。

>[!NOTE]
>
> 自定义着色器可能需要更新。 已将着色器 API更改为支持OpenPBR，有关详细信息，请参阅应用程序的“帮助”菜单中提供的更改日志。

### 新型硬表面自动展开

![](../assets/v12/v12_banner_uvs.jpg)

针对硬表面资产，增加了一种新的自动展开模式。

* <b>硬表面展开模式</b>

  自动展开设置中提供了<b>硬表面</b>选项。 它使扭曲最小化，并生成正交排列的UV版面，使其更适合于机械和硬表面网格。

  ![](../assets/v12/v12_unwrap_mode.jpg)

>[!NOTE]
>
> 有关自动展开的详细信息，请参阅[专用文档页面](../features/automatic-uv-unwrapping.md)。

### 杂项

![](../assets/v12/v12_banner_misc.jpg)

此版本中添加了其他功能和改进：

* <b>一次添加或删除多个通道</b>

  在引入OpenPBR后，可从<b>纹理集设置</b>访问的新窗口允许一次选择多个声道，这在设置OpenPBR工作流程使用的大声道列表时很方便。

  * 可通过<b>添加或删除频道</b>按钮在纹理集设置中访问新窗口。

    ![](../assets/v12/v12_channel_add_remove_button.png)

  * 该窗口概述了可在Painter中使用的所有渠道。

    ![](../assets/v12/v12_channel_window_small.jpg)

  * “<b>应用于所有纹理集</b>”按钮可用于一次编辑所有纹理集的声道配置。

    ![](../assets/v12/v12_channel_apply_all.png)

* <b>在纹理集间拼合所有实例</b>

  实例化图层和组上提供了一个新的<b>拼合所有实例</b>选项。 它会沿整个实例树向下遍历显示实例的每个纹理集，生成一个拼合的结果，并记录为一个撤消步骤。

  ![](../assets/v12/v12_flatten_instances.png)

* <b>统一的撤消历史记录</b>

  现在，烘焙和绘画模式共享相同的撤消历史记录。 在烘焙模式和绘画模式之间切换将记录为不可执行的步骤，因此动作只能在发生动作的模式下撤消。
