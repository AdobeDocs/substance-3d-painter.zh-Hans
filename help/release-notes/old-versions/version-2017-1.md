# 版本2017.1

Substance Painter会根据新的Substance优惠更改其版本号。 有关更多详细信息，请查看： <https://www.allegorithmic.com/welcome-to-substance>\
在此新版本中，我们希望通过提供新的增效工具来重点展示内容，该增效工具允许浏览Substance Source并将素材直接导入货架中。 我们还添加了大量新资源，以拓展您的创意可能性。

发行日期：*2017年6月20日*

## 主要功能

### 新插件：Substance Source

![](../../assets/source-optim.gif)

使用此新增效工具，现在可以&#x200B;**直接浏览**&#x200B;名为&#x200B;**Substance Source**&#x200B;的素材数据库，并将其&#x200B;**直接下载到货架**&#x200B;中，在您的项目中随时可用并随时可用。\
要打开Substance Source，只需单击应用程序主工具栏&#x200B;**中的Substance Source徽标**。 此时应会打开一个新窗口，允许浏览该库。

![](../../assets/source-overview.jpg){width="650px"}

### 新增内容：Alpha、流程、滤镜等

![](../../assets/new-alphas-gif.gif)

在此新版本中，我们将添加&#x200B;**300多个新资源**。 我们在阿尔法中添加了&#x200B;**科幻**、**几何**、**中世纪**&#x200B;甚至&#x200B;**凯尔特语**&#x200B;主题内容。 它还包括大量&#x200B;**新画笔**&#x200B;和&#x200B;**扫描的手印/指纹**。 我们还提供了一些方便的新滤镜，例如&#x200B;**MatFX细节Edge Wear**，它允许直接从绘制在网格上的常规信息&#x200B;**生成**&#x200B;划痕&#x200B;****。

以下是新内容的列表：

* **4种新字体**（日语、简体中文、打字机、区段）
* **230个新Alpha**（图案和扫描图像的混合）
* **50种新工艺**（主要是中世纪和现代服装的织物图案）
* **2张新环境地图**（蒙达拉因和新华别墅街）
* **9个新滤镜**（MatFX细节Edge Wear、夹具、HBAO等）

![](../../assets/alpha-content.jpg)![](../../assets/alpha-demo-image.jpg)

我们还更新了一些现有资源以使其更有效，例如&#x200B;**默认环境映射**，现在看起来更少黄色&#x200B;**：**

![](../../assets/new-env-map.gif)

## 发行说明

### 2017.1

（2017年6月20日发布）

**已添加：**

* [Plugin]新Substance Source增效工具（允许下载盘架中的资源）
* [字架] 4种新字体（日语+简体中文、打字机、分段）
* [盘架] 230种新Alpha（混合图案、画笔和指纹扫描）
* [货架] 50种新工艺（中世纪和现代服装的织物图案）
* [层架] 2张新环境地图（蒙达拉因和新大街）
* [Shelf] 9个新滤镜（MatFx细节Edge Wear、夹具、HBAO等）
* [托架]改进了默认全景图环境映射
* [托架]新的Arnold 5导出预设
* [脚本]允许将资源导入托架

**已知问题：**

* [导出]编辑导出预设时速度非常缓慢
