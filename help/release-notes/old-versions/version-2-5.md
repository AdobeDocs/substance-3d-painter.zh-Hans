# 版本2.5

**Substance Painter2.5**&#x200B;引入了许多新功能：从画笔设置中的不透明度（除了流之外）到烘焙8K额外映射等功能。

发行日期：*2017年2月21日*

## 主要功能

### 新建画笔不透明度

![](../../assets/brush-combined.gif){width="650px"}

现在，在Substance Painter中绘画时，**画笔参数**&#x200B;中的新设置是&#x200B;**不透明度**。\
**不透明度**&#x200B;控制画笔描边的&#x200B;**整体强度**，而相比之下，**流量**&#x200B;设置控制画笔描边内&#x200B;**每个单独的图章**&#x200B;的强度。 这意味着现在可以绘画和重绘相同的区域&#x200B;**，而无需创建重叠值**。 为此，请将“流量”设置为100，并将“不透明度”值设置为您喜欢的强度。 由于不透明度的工作原理，无法将其与笔压力联系起来。 对于这种控制，流量仍然是最佳选择。

我们还在此新参数旁添加了一个&#x200B;**新修饰符**，默认情况下，该参数位于&#x200B;**“A”**&#x200B;键上。 按此键将允许&#x200B;**继续上一个画笔描边**，而不是创建新的画笔描边。 这意味着您可以使用所需的绘画度来设置一个统一颜色，同时保留可能会移动的相机等。 另一个示例是继续使用克隆工具执行的复制。

![](../../assets/stroke-opacity-parameter.png)

### 8K全新烘焙和非方形分辨率

![](../../assets/baking-250-8k.png)

Baker已改进，支持分辨率高达&#x200B;**8192x8192**（8K加上消除锯齿功能），这意味着您现在可以使用其他地图以1:1的比率以8K导出。\
我们还添加了对&#x200B;**非方形**&#x200B;分辨率的支持。 例如，现在可以烘焙&#x200B;**4096x2048**&#x200B;的纹理。 为此，只需单击下拉菜单旁边的“**锁定**”图标以选择分辨率。

### 视口中对颜色配置文件的全新支持

![](../../assets/lut-example.jpg)

我们添加了&#x200B;**LUT**(纹理)的支持以控制Substance Painter中&#x200B;**视口**&#x200B;的渲染。 要应用配置文件，只需在“**显示设置**”窗口中启用“**颜色配置文件**”设置，并将LUT加载到专用插槽中。 它可以与&#x200B;**OpenGL**&#x200B;视口（绘画）和&#x200B;**Iray**&#x200B;渲染器配合使用。 一些示例默认自常见的&#x200B;**相机预设**&#x200B;到更多的&#x200B;**艺术效果**。 有关详细信息，请参阅文档的专用页： [颜色配置文件](../../features/post-processing/color-profile.md)

### 与Substance Designer6兼容的新Substance引擎

![](../../assets/font-shelf.png)

我们增加了对&#x200B;**Substance Designer6**&#x200B;的支持，这意味着使用&#x200B;**SD6**&#x200B;创建的资源可以打开并在&#x200B;**Substance Painter2.5**&#x200B;中使用！\
一个很好的示例是能够使用SD6的&#x200B;**新文本节点**&#x200B;并将其集成到Substance中。 通过这种方式，无需离开应用程序，即可创建&#x200B;**动态文本**&#x200B;并直接绘画它们。 **默认情况下，我们包含10种字体**，每种字体都有不同的样式，以覆盖最常见的用途。 您可以在&#x200B;**工具架**&#x200B;的“**程序化**”部分找到它们。

![](../../assets/text-sp250-optim.gif){width="400px"}

### 工具架中的新内容

![](../../assets/new-filters.jpg)

除了使用新工具架进行一些修复和改进之外，我们还添加了一组&#x200B;**新滤镜**，以改进绘画和纹理效果。 我们还&#x200B;**改进了**&#x200B;现有筛选器（如“**HSL**”）的行为。 我们在创建&#x200B;**新项目**（例如&#x200B;**Unity 5**&#x200B;和&#x200B;**虚构引擎4**）时还添加了新的&#x200B;**模板**。

### 支持自定义着色器UI的全新脚本改进

![](../../assets/ui-shader.jpg)

在此版本中，我们添加了一种&#x200B;**脚本和控制** **着色器参数**&#x200B;的方法。 我们还添加了对使用&#x200B;**自定义UI**&#x200B;而不是默认UI的支持，从而开启了多种新的可能性，例如&#x200B;**动画着色器**。\
有关更多详细信息，请查看应用程序的“帮助”菜单中的脚本文档。
