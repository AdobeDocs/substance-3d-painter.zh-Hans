# 版本2021.1 (7.1.0)

**Substance Painter2021.1 (7.1.0)**&#x200B;引入了多种新功能和改进，例如几何蒙版以及图层栈栈中的效果复制和粘贴。

版本数据： *2021年1月28日*

>[!NOTE]
>
> 此版本将Ubuntu和MacOS支持的最低版本分别提高到18.04和10.14。 有关详细信息，请参阅[技术要求](../../getting-started/system-requirements.md)。

## 主要功能

### 新几何形状蒙版

![](../../assets/header-geo-mask.jpg)

几何蒙版是图层栈栈中的新蒙版工具，允许根据网格名称或UV磁贴隐藏几何图形。 它是之前命名的UV拼贴蒙版的演变，基于UDIM数值遮蔽了几何图形。

与常规绘画（或使用[多边形填充](../../painting/tool-list/polygon-fill.md)时）相比，此新工具是一种更好的蒙版几何方法，因为它受益于多种引擎优化。 该操作也是非破坏性的，因为它不存储几何信息（如表面或顶点），而仅存储网格名称或UV拼贴编号，因此重新导入网格不会破坏蒙版。 另一个好处是隐藏几何允许在纹理集中之前不可访问的表面上绘画，这避免了将对象拆分为多个纹理集的需要，例如。

* **在图层上新建几何蒙版**\
  几何蒙版可在[图层栈叠](../../interface/layer-stack/layer-stack.md)中的任何图层上自动使用。 默认情况下，它没有任何效果，表示图层完全可见。\
  几何图形蒙版有自己的上下文菜单，可用于快速选择或取消选择其所有项目，还可以将其值复制到另一个图层。

  ![](../../assets/layer-stack-geo-mask-icon.png)

  ![](../../assets/geo-mask-contextual-menu.png)

* **编辑几何图形蒙版属性**&#x200B;几何图形蒙版遵循与其他图层的上下文相同的逻辑（如编辑蒙版或实例化属性）。 要进入几何蒙版编辑模式，只需单击图层右侧的虚线方块即可。 要退出几何图形蒙版，请单击同一图层的内容或绘制蒙版。

  ![](../../assets/geo-mask-editing_1.gif)

* **按网格名称或UV磁贴使用蒙版**\
  几何蒙版属性的顶部是一个控制蒙版模式的下拉菜单。 可以按UV拼贴编号或按网格名称来选择蒙版。 此下拉列表被禁用，并仅在项目不使用UV磁贴工作流程时设置为网格名称。

  ![](../../assets/geo-mask-masking-mode.png)

* **通过属性设置几何蒙版**\
  在编辑几何图形蒙版时，属性窗口将根据与当前纹理集相关的几何图形显示网格名称（或UV拼贴）的列表。

  * 该列表上方的数字指示在可用的网格总数/UV磁贴中未被蒙版遮盖的网格数。
  * 数字旁边的菜单提供快速控件，可选择所有项目或不选择任何项目，甚至可反转当前选区。
  * 下面的列表定义了哪些项目被蒙版或不被蒙版。 与应用程序中的其他列表一样，可以单击并拖动以同时启用/禁用多个项目，也可以使用&#x200B;**按住ALT键并单击**&#x200B;来隔离项目。

  ![](../../assets/geo-mask-menu.gif) ![](../../assets/geo-mask-quick-list-edit.gif)

* **通过视口添加蒙版几何**\
  几何蒙版选区也可以在2D和3D视图中更改。 只需将鼠标移至应可见/隐藏的零件上，然后单击它以切换其状态。 在编辑几何图形蒙版时，蒙版几何图形会显示为灰色和对角线效果。 也可以通过单击并拖动一次选择多个项目来执行矩形选择。\
  ![](../../assets/geo-mask-editing-viewport-3d.gif) ![](../../assets/geo-mask-editing-viewport-2d.gif)

* **绘制隐藏/无法访问的几何图形。**\
  在几何图形蒙版中选择要遮盖的几何图形后，可以启用视口顶部的&#x200B;**隐藏/忽略排除的几何图形**&#x200B;按钮（或按下&#x200B;**ALT+H**&#x200B;快捷键）。 启用后，将隐藏排除的几何（以及其他纹理集），以仅显示当前图层包含/可绘制的几何。 使用此选项可涂抹之前被遮挡或不可触及的区域。 此选项也适用于任何类型的图层。

  >[!NOTE]
  >
  > 使用蒙版几何形状绘画将保持动态状态：如果某些阻止绘画的几何形状在画笔描边制作时最初处于隐藏状态，然后被取消蒙版，则会再次阻止之前制作的画笔描边。

  ![](../../assets/geo-mask-paint-through.gif)

### 全新复制和粘贴图层栈叠效果

![](../../assets/header-effects.jpg)

现在，可以在图层和图层栈叠之间复制效果，方法与常规图层相同。

现在可以选择多项，并且提供一次复制和粘贴多个效果的可能性。

为方便起见，在图层上从蒙版复制或移动效果时，如果没有蒙版，则会自动添加效果。 这是因为图层内容和蒙版中的效果彼此不兼容。 这意味着将效果从蒙版复制到图层的内容将自动切换到蒙版（或创建一个）。

* **通过上下文菜单复制和粘贴**\
  右键单击纹理集图层栈栈中的任何效果，然后选择剪切或复制操作。 然后在任意图层上再次右键单击，选择“粘贴”以移动或创建所需效果的副本。 我们还借此机会重新制作上下文菜单，并允许访问更多功能：

  ![](../../assets/effects-contextual-menu.png)

* **使用键盘快捷键复制和粘贴**\
  与任何图层相同，键盘快捷键&#x200B;**CTRL+C**（复制）/**CTRL+X**（剪切）和&#x200B;**CTRL+V**（粘贴）可用于根据当前选区复制效果。 与图层一样，效果也会插入到当前选区的上方。

  ![](../../assets/copy-paste-effect-keyboard.gif)

* **使用键盘快捷键快速复制效果**\
  使用&#x200B;**CTRL+D**&#x200B;复制当前选区，或在拖动&#x200B;**任何效果时按住** ALT键以将其复制到所需位置：

  ![](../../assets/copy-paste-drag-alt.gif)

* **跨图层移动效果**\
  除了复制和复制之外，现在还可以通过将效果从一个图层拖放到另一个图层来移动效果：

  ![](../../assets/drag-effects.gif)

### 新增的一般功能和改进

![](../../assets/header-misc.jpg)

此版本中进行了一些改进：

* **为每个UV图块添加描述**\
  现在，可以通过“纹理集列表”为每个UV图块添加描述。 这使得项目更易于导航，特别是在导出和生成时，因为可以在这些上下文中看到描述。\
  要添加或编辑描述，只需单击“纹理集列表”窗口中的“UV平铺”，然后进入“纹理集设置”窗口进行编辑即可。

  ![](../../assets/uv-tiles-descriptions.png)

  ![](../../assets/uv-tiles-description-baking.png) ![](../../assets/uv-tiles-description-export.png)

* **新建图层栈栈缩略图**\
  已改进优化的图层栈叠缩览图。 现在，已为填充图层显示素材球体，即使在使用[UV磁贴](../../features/uv-tiles/uv-tiles.md)工作流程时，也更容易导航和查看每个图层的主要属性。 缩览图是根据图层信息生成的，但不考虑效果，以免重新计算过于频繁。

  ![](../../assets/layer-stack-thumbnails.png)

* **改进了图层栈栈中的几何蒙版退出**\
  如果图层栈叠中的文件夹没有蒙版，则退出几何蒙版（以前称为UV拼贴蒙版）可能会很困难。 这是因为除了选择另一个图层之外，没有其他上下文可供打开。 现在可以单击文件夹缩览图以退出“几何图形蒙版”。 在编辑几何蒙版时，还可以将素材或智能素材从层架拖放到视口中。

  ![](../../assets/geo-mask-folder.gif)

  ![](../../assets/drag-drop-geo-mask.gif)

* **在烘焙窗口中按住Alt键单击新选区**\
  现在可以通过&#x200B;**Alt +鼠标单击**&#x200B;隔离烘焙窗口中的网格映射列表以隔离要烘焙的特定映射，而不是必须手动排除它们。 相同的快捷键可用于重新启用所有网格图。

  ![](../../assets/baking-alt-click.gif)

* **新建烘焙当前纹理集按钮**\
  “烘焙”窗口底部添加了一个新按钮，可以快速轻松地重新烘焙纹理集。 使用此按钮不会影响之前定义的自定义选择，而是将烘焙整个纹理集（包括其所有UV磁贴，如果有的话）。

  ![](../../assets/bake-current-texture-set.png)

### 新Substance 引擎更新

![](../../assets/header-engine-v8.jpg)

该Substance 引擎已更新到版本8，以支持最新的Substance文件格式及其功能。

有关新Substance 引擎功能的更多详细信息，请查看[此文档页面](https://helpx.adobe.com/substance-3d/unlisted/documentation/sddoc/version-2020-2-10-2-0-200574252.html)。

### 在Iray中新增Nvidia RTX 3000支持

![](../../assets/banner-iray.png)

[Iray渲染器](../../features/iray-renderer/iray-renderer.md)已更新到最新版本，现在支持新的Nvidia Ampere GPU（RTX 3000系列和Quadro A系列）。

>[!NOTE]
>
> 经过此次更新，不再支持Kepler GPU（GeForce 600和700系列），将改为在CPU上完成Iray渲染。

### 新的Python功能

![](../../assets/header-python.jpg)

Python API收到了几项新功能。 为了便于理解和学习API，还对该文档进行了重新设计，尤其是其示例。

* **资源和货架管理**\
  资源模块已改进，现在可以：
  * 创建和管理货架。
  * 搜索或导入货架和项目中的资源。
  * 了解托架是否正在搜索（从而了解资源何时可以使用）。
  * 将自定义缩略图分配给层架中的资源。

* **UV磁贴信息**\
  现在可以查询纹理集的“UV平铺”列表。 这打开了在特定范围的UDIM磁贴上创建自定义导出内容的可能性。

* **项目版本状态**\
  添加了一个新的函数和事件，以了解是否可以编辑项目。 这有助于了解计算是否正在进行以及是否无法修改项目的属性。

>[!NOTE]
>
> Python API文档可从应用程序的帮助菜单访问。
