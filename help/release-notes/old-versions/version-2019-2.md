# 版本2019.2

**Substance Painter2019.2**&#x200B;为面包师带来了新的强大功能，并在货架上提供了一组新的智能素材和智能蒙版。

发行日期：*2019年7月25日*

## 主要功能

### 对烘焙师的工作流程进行了改进

![](../../assets/header-image-vizu.jpg)

此版本中的烘焙工作流程经过改进，包含一些新增功能。 这些改进将加速并简化日常的Substance Painter工作。

* **烘焙过程可视化**\
  默认情况下，使用此新版本后，任何烘焙过程现在都可以在视区中看到。 它允许实时预览生成器的结果，甚至根据需要取消该结果，而无需等到流程结束才能提供更快的迭代。 可通过进入主要设置并取消选中“**烘焙选项**”部分下的“**启用实时预览烘焙过程**”设置来禁用此行为。

  ![](../../assets/baking-options-v2.png)

  ![](../../assets/bake-process.gif){width="500px"}
* **改进了烘焙对话框**\
  烘焙对话框已修改，现在可显示当前烘焙过程的更佳状态。 现在有一个计数器指示将计算多少个纹理，以及每个烘焙者和所计算内容的纹理集的显式列表。 如果出现错误，面包师姓名旁边会显示红十字。 该过程结束时，通过新按钮可快速打开日志窗口以详细了解问题。\
  ![](../../assets/baking-dialog.png)
* **正在取消烘焙**&#x200B;烘焙过程不再锁定应用程序。 Substance Painter现在的响应速度更快，这意味着可以取消当前正在进行的烘焙，而无需等待其结束。 取消不会立即生效，但可能需要几秒钟才能生效。 这是因为烘焙过程在内部处理块中的纹理，并且在计算块时无法停止。 取消烘焙过程时，“烘焙”窗口自动重新打开。\
  ![](../../assets/baking-cancel-optim.gif)

### 面包师的性能改进

![](../../assets/header-image-baker.jpg)

随着工作流程的改进，我们亦抓紧机会为我们的烘焙师提供更新并提升其表现。 我们还添加了DXR和Optix支持，以实现GPU 射线追踪，从而能够以比以前快得多的速度烘焙。 但请注意，GPU 射线追踪仅影响环境遮蔽和Thickness烘焙器。

* **CPU光线追踪已改进**\
  现在，CPU上的光线追踪计算比以前快2到3倍。 因此，即使您的GPU与GPU 射线追踪不兼容，您仍会在总体上获得性能改进。
* **对DXR和Optix的GPU 射线追踪支持**\
  在兼容的硬件环境下，烘焙器可以直接在GPU上进行计算，这极大地减少了计算时间，尤其是在启用了消除锯齿并定义了大量光线时。 DXR是默认选项（如果可用），否则将使用Optix。 可以通过进入[主要设置](../../interface/settings/settings.md)并查找“**烘焙选项**”来禁用GPU 射线追踪：

  ![](../../assets/baking-options-v2.png)

>[!NOTE]
>
> 要启用GPU 射线追踪功能，请确保更新到以下驱动程序： **Nvidia驱动程序430.86**。\
> DXR在RTX GPU和[GeForce GTX 10xx GPU](https://www.nvidia.com/en-us/geforce/news/geforce-gtx-dxr-ray-tracing-available-now/)上可用。 DXR还要求Windows 10必须是最新版本才能访问（1809版），有关详细信息，请参阅此页面。

>[!WARNING]
>
> 使用GPU 射线追踪时，如果高多边形网格无法适合VRam，烘焙器可能会失败。 发生此情况时，建议进入[主要设置](../../interface/settings/settings.md)，并在“**烘焙选项**”部分下禁用“**GPU 射线追踪**”设置。 之后，您只需重新启动烘焙过程即可。

### 其他新增功能和改进

![](../../assets/header-image-misc.jpg)

在此版本中，我们还添加并修改了一些内容，以改善Substance Painter内部的生活质量。

* **改进的旋转机械手**\
  以往旋转机械手速度稍慢，使得旋转有时显得枯燥。 现在，旋转速度会与相机和场景大小关联。
* **提升了视口缩小时高DPI屏幕上的性能**\
  在[主设置](../../interface/settings/settings.md)中，现在有一个名为“视口缩放”的新参数，其值为“**无**”且“**自动**”（默认）。 当Substance Painter检测到屏幕使用HDPI缩放（例如MacOS上的Retina屏幕）时，它将自动将视口分辨率除以2。 此行为可以避免绘制过大的视区，并改善总体性能，而不会造成任何明显的质量损失。

  ![](../../assets/settings-viewport-downscale.png)
* **用于脚本的新控制台插件**\
  我们创建了一个新插件，以便从我们的脚本API轻松运行命令。 它在Github上可用： <https://github.com/AllegorithmicSAS/painter-plugin-console>。 控制台还支持自动完成。

  ![](../../assets/console-plugin.png)
