# 用户数据

本页介绍可在Substance图形上添加以执行特定行为的自定义属性（用户数据）。\
用户数据设置通常应用于图形的输入或输出节点，以指示应用程序应如何解释它们。 这允许以某种方式请求图形输入以应用效果是已知的上下文（例如：请求特定的色彩空间），或者指示在应用程序之后需要应用额外转换时如何进行输出。

* 使用数据设置定义为&#x200B;**键=值**
* 用分号(**；**)分隔多个设置

## 色彩空间

**色彩空间**&#x200B;设置可用于请求具有特定色彩空间的Substance图形输入，或定义以特定方式配置的输出。 例如，指定法线映射输出的格式。

语法示例： **colorspace=$working**

上下文概述：

* **颜色按钮**：颜色图表的属性中的Substance按钮构件。
* **图形输入/输出**：连接到通道的图形的输入或输出节点（例如：基色）。
* **图像输入**：图形的一般输入，与特定通道无关。

>[!NOTE]
>
> 随着色彩管理的引入，与色彩空间设置相关的几种行为发生了变化：
> 
> * 下表首先列出了版本8.1之前兼容的色彩空间设置。 第二部分仅适用于版本8.1及更高版本。
> * 关于可以在其中使用色彩空间设置的上下文，只有版本8.1中的颜色按钮才能定义色彩空间。 在以前的版本中，假定它们位于显示空间(sRGB)中。
> 
> **snorm**&#x200B;和&#x200B;**unorm**&#x200B;色彩空间/变换不应与GPU纹理格式混合，它们的用途不同。

| 色彩空间 | 上下文可用性 | 描述 |
| --- | --- | --- |
| **自动** | 颜色按钮图形输入/输出图像输入 | 默认。 应用程序根据输入节点属性和插入输入中的图像确定要执行的色彩空间转换。 |
| **线性** | 颜色按钮图形输入/输出图像输入 | 标准sRGB IEC 61966-2-1:1999色彩空间，具有线性灰度系数/色调曲线。 仅适用于&#x200B;**旧版**&#x200B;色彩管理模式。 |
| **srgb** | 颜色按钮图形输入/输出图像输入 | 标准sRGB IEC 61966-2-1:1999色彩空间。 仅适用于&#x200B;**旧版**&#x200B;色彩管理模式。 |
| **通过** | 颜色按钮图形输入/输出图像输入 | 已弃用。 在旧版色彩管理模式下解释为&#x200B;**线性**，在OCIO/ACE模式下解释为&#x200B;**原始**。 应替换为&#x200B;**raw**。 |
| **snorm** | 图形输入/输出图像输入 | 已签名规范化。 请求输入图像在[0， 1]范围内。 对于8位输入图像，这意味着中间值为127。 对于浮动图像输入，中间是0.5，不执行任何固定。 |
| **normalxyzright** | 图形输入/输出图像输入 | OpenGL法线贴图格式 |
| **normalxyzleft** | 图形输入/输出图像输入 | 法线贴图格式。 |
|  |  |  |
| **无序** | 图形输入/输出图像输入 | 浮动输入，无范围/限制。 |
| **数据** | 颜色按钮图形输入/输出图像输入 | 无符号规范化或浮点。 非颜色信息。 |
| **原始** | 颜色按钮图形输入/输出图像输入 | 使用此设置时，不会应用任何颜色变换。 |
| **$standardsrgb** | 颜色按钮图形输入/输出图像输入 | 标准sRGB IEC 61966-2-1:1999色彩空间。 |
| **$正在工作** | 颜色按钮图形输入/输出图像输入 | 工作色彩空间取决于色彩管理设置。 将与非色彩管理通道和单通道（模板、Alpha、蒙版）的数据相同 |
| **$raw** | 颜色按钮图形输入/输出图像输入 | **raw**&#x200B;的别名。 |
| **$auto** | 颜色按钮图形输入/输出图像输入 | **自动**&#x200B;的别名。 |

## Alpha模式

**alpha**&#x200B;设置可用于指定如何组合颜色输入或输出(RGBA)的alpha。

语法示例： **alpha=premultiplied**

| 设置 | 描述 |
| --- | --- |
| 直的 | 请求或将Alpha定义为直接。 |
| 预乘 | 请求或将Alpha定义为预乘。 |
| 无 | 通过，按原样使用给定的Alpha。 |

>[!NOTE]
>
> 通道&#x200B;**不透明度**&#x200B;默认视为&#x200B;**直通**。

## 图像输入默认颜色

Substance图形图像输入的默认颜色为黑色，Alpha设置为0。 **defaultcolor**&#x200B;设置允许在图形的图像输入为空时定义不同的值

可使用浮动值（范围[0， 1]）或整数值（范围[0， 255]）指定颜色。 每个组件值由逗号分隔，而浮点值使用点作为小数分隔符。 如果浮点没有点，则将其视为整数。

语法示例：

* **defaultcolor=(1.0,0.5,0.0)**
* **defaultcolor=(0,128,255)**

## 图像输入填充

默认情况下，Substance图表的图像输入没有任何内边距，出于性能原因，UV 岛之外的区域通常填充一种均匀的颜色。 可以使用padding设置来请求无限扩展，例如，可用于滤镜以避免创建接缝。

语法示例： **p****adding=extend**

## 默认禁用输出

向槽中添加Substance（类似于填充图层工具的素材槽）时，可以通过“元数据”文本字段指定以不启用特定通道：

* 在特定输出节点（如素材）上： **disable=(true)**
* 在常规输出节点（如滤镜）上： **disable=（Height，扩散，Specular）**

在加载Substance时，此通道不会在用户界面中启用，因此在图层栈叠中无效。 用户仍然可以重新启用该通道。

## 将输出指定为公共蒙版/Alpha

Substance图形的输出可以在其他输出上使用共享Alpha通道/蒙版。

有两种方式可以做到这一点：

* 创建标识符为&#x200B;**channels\_node**&#x200B;的输出Alpha
* 或在特定输出节点上添加以下userdata： **IsChannelsAlpha=true**

一些条件可能适用：

* 如果标识符为&#x200B;**channels\_node**&#x200B;的输出节点存在，而其他输出Alpha没有userdata，则此节点将用作通道掩码。
* 如果输出具有userdata，则只要没有&#x200B;**channels\_node** Alpha，就会将其用作通道蒙版。
* 如果同时存在&#x200B;**channels\_node** Alpha和包含userdata的节点，则将首先使用&#x200B;**channels\_node**&#x200B;输出Alpha。
* 如果有多个节点拥有用户数据，则应用程序找到的第一个节点将用作通道掩码。 发现输出的顺序不能保证与Substance图定义的顺序相同。

>[!NOTE]
>
> 此设置仅适用于在&#x200B;**材质模式**&#x200B;中使用的Substance图形。 不适用于滤镜、生成器等

## 设置素材输出的默认混合模式
