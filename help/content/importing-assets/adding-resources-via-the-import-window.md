# 通过导入窗口添加资源

## 打开导入窗口

有三种不同的方法可在Substance 3D Painter中打开导入窗口：

* 通过&#x200B;**文件>导入资源……**&#x200B;菜单项

![](../../assets/05-01-importfilemenu.jpg)

* 通过“资源”窗口中的&#x200B;**专用按钮**

![](../../assets/05-03-importbutton.jpg)

* 通过&#x200B;**将一个或多个文件/文件夹中的**&#x200B;拖放到“资源”窗口中

![](../../assets/05-02-importdnd.gif){width="700px"}

## 配置导入窗口

![](../../assets/05-04-importwindow.jpg)

* **1 — 添加资源**：允许选择要导入的其他文件，这将将这些文件添加到“导入”窗口中显示的列表中。
* **2 — 删除所选资源：**&#x200B;删除列表中选定的文件。
* **3 — 下拉筛选条件**：允许按使用情况筛选文件列表。 这对于隔离具有“未定义”类型的资源非常有用。
* **4 — 使用情况** ：有几种不同的使用情况类型可用。 建议的使用列表可能会根据要导入的文件格式而更改。 如果您的文件格式只有一种使用类型（例如，Painter预设.sppr将自动按此定义），或者该文件已在其创建者已在原始Designer图表中预定义，则可能会为您的文件预先选择使用方式。
* **5 — 前缀** ：前缀可以是用于定义存储资源的位置的文件夹路径。
* **6 — 文件名** ：当前资源的名称。 有时，可以指示存储资源的文件夹，但在导入过程中不会使用此信息。
* **7 — 导入位置** ：可以是 — 
  * **当前会话** ：在临时会话中，重新启动应用程序后资源将丢失。
  * **项目“项目名称”** ：添加到当前打开的项目文件中。 资源嵌入在&#x200B;**spp**&#x200B;文件中。
  * **盘架“盘架名称”** ：放入定义为可写的当前库。 请参阅此页面以了解详细信息： [库配置](../../interface/settings/libraries-configuration.md)。

您可以在导入窗口中选择多个资源（使用常见的系统快捷方式）以快速编辑它们的使用情况。
