# “窗口”菜单

![](../../assets/window-menu.png)\
窗口菜单允许显示窗口列表以及这些窗口在界面中是否可见。 您还可以使用工具栏菜单来隐藏一些工具栏。

| 操作 | 描述 |
| --- | --- |
| **个视图** | 列出界面中可用的窗口（复选框指示当前是否可见）。 |
| **工具栏** | 列出界面中可用的工具栏（复选框指示它当前是否可见，以允许切换它们）：停靠、增效工具和工具。 |
| **隐藏UI** | 隐藏接口的所有窗口和坞站，并最大化视口。 |
| **重置UI** | 将当前窗口布局重置为默认值。 |
