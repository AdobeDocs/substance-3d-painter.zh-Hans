# 视区菜单

![](../../assets/viewport-menu.png)

视区菜单可用于更改[视区](https://substance3d.adobe.com/)的显示模式。

| 操作 | 描述 |
| --- | --- |
| **显示材质** | 将视区切换到&#x200B;**材质**&#x200B;模式，这将显示具有光照和着色的3D模型。 |
| **显示下一个频道** | 将视口切换到单独模式以显示下一个“纹理集”通道。 |
| **显示上一个频道** | 将视口切换到单独模式以显示上一个“纹理集”通道。 |
| **显示下一个网格图** | 将视口切换到单独模式以显示下一个烘焙网格映射类型。 |
| **显示上一个网格图** | 将视口切换到单独模式以显示上一个烘焙网格映射类型。 |
| **显示整个网格** | 调整视口相机以使其在3D模型上居中。 |
| **已启用快速蒙版** | 有关详细信息，请参阅[快速蒙版](../../painting/tool-list/quick-mask.md)页面。 |
| **编辑快速蒙版** | 有关详细信息，请参阅[快速蒙版](../../painting/tool-list/quick-mask.md)页面。 |
| **反转快速蒙版** | 有关详细信息，请参阅[快速蒙版](../../painting/tool-list/quick-mask.md)页面。 |

有关显示模式的详细信息，请参阅[显示设置](../display-settings/display-settings.md)。

有关快速蒙版的更多信息，请参阅[专用页面](../../painting/tool-list/quick-mask.md)。
