# “帮助”菜单

<table style="table-layout:auto">
  <tr style="border: 0;">
    <td style="border: 0;" valign="top">帮助菜单包含链接和选项，可让您了解有关Substance 3D Painter的更多信息。 这包括教程、发行说明和文档等有用的内容，或者您可以用来解决Painter本地安装问题的地方，包括访问日志或报告错误的方式。</td>
    <td style="border: 0;" valign="top"><img src="../../assets/help-menu.png" alt=""/></td>
  </tr>
</table>

| 操作 | 描述 |
| --- | --- |
| 教程 | 链接到与该应用程序相关的正式[教程](https://helpx.adobe.com/cn/substance-3d/unlisted/tutorials.html)。 |
| 发行说明 | 链接到[发行说明](../../release-notes/all-changes.md)。 |
| 文档 | 指向此文档的链接。 |
| 快捷键列表 | 链接到[快捷方式](../settings/shortcuts.md)文档。 |
| 脚本文档 | 链接到各种脚本API的本地文档。 |
| 论坛 | [应用程序论坛](https://community.adobe.com/t5/substance-3d-painter/bd-p/substance-3d-painter)的链接。 |
| 报告错误 | 打开错误报告窗口以发送信息。 |
| 显示日志 | 在默认的TXT文件编辑器中打开当前Painter会话的日志文件。 |
| Export log | 导出日志文件，以寻求我们支持的帮助。 |
| 提供反馈 | 链接到我们的[功能请求](https://feedback.substance3d.adobe.com/forums/261284-substance-3d-painter)平台。 |
| 管理我的帐户 | 打开[account.adobe.com](http://account.adobe.com)以管理您的帐户和订阅。 |
| 注销 | 注销当前已登录的Adobe帐户。 |
| 欢迎屏幕 | 打开[欢迎屏幕](../../getting-started/getting-started.md)窗口。 |
| 新增功能 | 显示新增功能屏幕，了解有关当前更新中更改的详细信息。 |
| 主屏幕 | 打开主屏幕。 |
| 检查更新 | 打开[更新检查器](../miscellaneous/update-checker.md)窗口。 |
| 关于Substance 3D Painter | 打开“关于”窗口，其中显示应用程序版本、法律声明和其他详细信息。 |
| Partners | 访问有关集成到Painter中的合作伙伴软件的信息。 |
