# “文件”菜单

![](../../assets/file-menu.png){width="150px"}

“文件”菜单包含用于创建和保存项目的操作，以及用于将资源导出和导入到项目的操作。

| 操作 | 描述 |
| --- | --- |
| **新建** | 打开新建项目创建窗口。 有关详细信息，请参阅： [项目创建](../../getting-started/project-creation.md)。 |
| **打开** | 在磁盘上打开现有项目文件。 |
| **最近使用的文件** | 列出最近打开的所有项目。 |
| **打开示例** | 打开随应用程序一起提供的示例项目之一。 |
| **关闭** | 关闭当前打开的项目。 |
| **保存** | 在当前位置保存项目。 |
| **保存并压缩** | 将当前项目保存到位并进行压缩（减少磁盘上的占用空间）。 |
| **另存为** | 使用新的名称和位置保存当前项目。 |
| **另存为副本** | 将当前项目以新名称和位置保存为副本，同时保持当前项目打开。 |
| **另存为模板** | 将当前项目设置保存到可用于新项目的模板文件中。 |
| **洁净** | 从当前项目中移除所有未使用的资源（将在下次&#x200B;**保存**&#x200B;后生效）。 |
| **导入资源** | 打开导入资源窗口。 |
| **导出网格** | 打开允许将当前项目导出为3D模型文件的网格导出窗口。 |
| **导出纹理** | 打开可将当前项目导出为位图纹理的纹理导出窗口。 |
| **发送到** | 列出所有&#x200B;**发送到**&#x200B;操作以将项目发送到其他应用程序。 |
| **退出** | 关闭应用程序。 如果当前项目具有未保存的更改，则会提示一条消息。 |

>[!NOTE]
>
> 可通过两种方式保存项目：
> 
> * **增量** ：默认方法，在执行常规存储时使用。 只有更改的信息才会更新到磁盘上的项目文件中。 此方法允许快速保存项目，而无需完全重写项目文件。
> * **完全/压缩** ：如果执行清理操作，或者使用“保存并压缩”操作保存项目，则该方法将在磁盘上完全重写项目。 此方法可消除项目碎片并减少占用空间。 请参阅： [项目很大](../../technical-support/workflow-issues/project-issues/projects-are-really-big.md)。
