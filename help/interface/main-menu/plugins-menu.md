# JavaScript和Python插件菜单

![](../../assets/plugins-javascript.png)

JavaScript和Python菜单列出了Painter在启动时加载的所有插件。 根据增效工具使用的脚本API（Javascript或Python），增效工具被分成两个菜单。

应用程序发现的每个插件都将在各自的菜单中添加一个条目以访问其他功能。 在菜单中，每个增效工具都有以下选项：

* **禁用/启用**：打开或关闭插件。
* **重新加载**：重新加载插件，以防脚本在应用程序运行时更新。
* **配置**：如果插件支持此功能，则显示配置插件的功能/窗口。
* **关于**：如果插件支持此功能，则显示有关插件的信息。

要了解Painter提供的默认增效工具或如何自己创建新增效工具，请参阅专用的[增效工具](../../features/plugins/plugins.md)页面。
