# Substance 3D Assets

![](../assets/v10_banner_3d_assets_2-1.jpg)

<b>Substance 3D Assets</b>停靠区允许直接在应用程序中浏览同名的联机库。 可在以下地址找到原始库： <https://substance3d.adobe.com/assets>

>[!NOTE]
>
> 应用程序的Steam版本不提供Substance 3D Assets窗口。

## 位置

默认情况下，窗口将停靠为常规资源窗口旁边的选项卡。 如果窗口已关闭，则可以从界面最右侧的停靠工具栏重新打开该窗口。

![](../assets/v10_3dassets_location_tab.png)

![](../assets/v10_3dassets_location_dock.png)

### 浏览资源

要浏览资源，您可以使用窗口中提供的界面。 顶部显示了一个搜索字段，可用于缩小搜索范围，并且还提供了一个过滤器。

![](../assets/v10_3d_assets_search.jpg)

### 正在下载资源

单击资源的“下载”按钮后，这些资源将开始下载，并显示在窗口的下载管理器中。 要查看该文件，只需单击窗口左下角的按钮即可。

此列表仅显示应用程序当前会话期间下载的资源。

成功下载资源后，该资源将显示在常规<b>资源</b>窗口中。

![](../assets/v10_3d_assets_download.png)

>[!NOTE]
>
> 资源的下载位置取决于默认库。 可以在首选项中更改此位置，请参阅专用的[文档页面](assets/adding-a-new-library.md)。

### “控制”菜单

窗口右下角的按钮提供了一些操作：

* <b>打开文件夹位置</b>：打开文件资源管理器到当前库的位置。 这允许在磁盘上浏览下载的资源（包括过去的会话）。
* <b>重新加载页面</b>：在窗口中重新加载界面。
* <b>上一页</b>：导航到窗口内的上一个界面。
* <b>下一页</b>：导航到窗口中的下一个界面。

![](../assets/v10_3d_assets_menu-1.png)
