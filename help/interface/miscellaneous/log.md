# 日志

![](../../assets/log.png)

该日志是Substance 3D Painter和[插件](../../features/plugins/plugins.md)可以显示状态更新、跟踪进度、警告和错误的地方。

日志分为两个选项卡。

* **常规选项卡**&#x200B;显示与您的项目和场景相关的信息，包括导出详细信息。
* **“资源”选项卡**&#x200B;显示与&#x200B;**“资源”面板**&#x200B;具体相关的错误和日志。
