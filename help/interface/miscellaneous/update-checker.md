# 更新检查程序

![](../../assets/update-cc.png)

您可以从Creative Cloud桌面检查Substance 3D Painter更新。 导航到“应用程序”选项卡，查看已安装的应用程序部分。 如果更新已可供下载，**可用更新**&#x200B;将显示在应用程序名称下。

通过打开Painter并使用&#x200B;**帮助>发行说明**，您可以访问当前版本的发行说明。
