# 按路径筛选

**按路径筛选**&#x200B;是额外的部分，可用于浏览您的资源。 它具有与面包屑相同的结构，这意味着您可以查看资源的路径/位置。

![](../../assets/01-01-panel.jpg)

默认情况下，将激活&#x200B;**隐藏不适用的文件夹**，这样您就可以在UI中隐藏空文件夹。 例如，如果您将“按路径筛选”与特定搜索词相结合或选择一种资源类型，这样做将非常方便，因为这样做将允许您仅查看包含搜索的相关位置。

![](../../assets/01-02-hideempty.gif)
