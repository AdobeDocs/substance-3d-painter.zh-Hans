# 保存的搜索

“保存的搜索”与“按路径过滤”是另一个可以在“资源”窗口中打开的新部分。 它允许您保存最常用的搜索和查询，随时轻松访问它们，甚至可以将它们作为新的子库选项卡打开，该选项卡可以单独停放。

![](../../assets/02-01-savedsearches.jpg)

要创建保存的搜索，可以合并不同类型的导航 — 您可以在搜索字段中键入书面查询，选择所需的资源类型（或多个资源类型）以及通过按路径或痕迹过滤的位置。 所有这些搜索都可以保存为单个保存的搜索，也可以分解为单独的保存搜索。 例如，您可能想为使用动态描边的画笔创建一个保存的搜索，因为它是您经常使用的东西。

>[!NOTE]
>
> 保存的搜索保存在配置文件中，可以手动编辑。 要了解更多信息，请查看[手动添加保存的搜索](../../pipeline-and-integration/resource-management/adding-saved-searches-manually.md)。

创建保存的搜索后，它将显示在您的搜索列表中。 可以右键单击它以创建新的子库选项卡，重命名或删除它。

![](../../assets/02-02-savesearch.gif)

您还可以通过将鼠标悬停在搜索字段中的搜索标签上来查看有关搜索内容的信息。

![](../../assets/02-03-searchinfo.jpg)
