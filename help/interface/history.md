# 历史记录

![](../assets/history-list.png)\
“历史记录”窗口列出了在当前打开的项目中所执行的所有操作和修改。

* 可以单击列表中的每个元素，以返回到创建/应用操作时的项目状态。
* 当新操作不在该列表的最后一个元素上时，将擦除现有的将来操作，并替换为新的操作。
* 这些操作是项目的全局操作，因此在两个不同的纹理集中创建图层将显示在同一列表中。

虽然所有信息都保存在项目中（以便能够重新绘制/重新纹理化所有内容），但如果关闭并重新打开项目，将无法访问“历史记录”列表。 历史记录列表仅在当前会话期间可用。
