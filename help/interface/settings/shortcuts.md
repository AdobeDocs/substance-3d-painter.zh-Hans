# Shortcuts

![](../../assets/settings-shortcuts.png){width="400px"}

此页面列出了所有可用的键盘和鼠标快捷键。

## 快捷键概述

有关所有可用快捷键的简要概述，请查看我们的图形[，我们的教程中提供了该图形](https://helpx.adobe.com/substance-3d/unlisted/tutorials/courses/substance-3d-painter-keyboard-shortcuts.html) 。

## 如何更改快捷键

![](../../assets/shortcut-edit.gif)单击快捷键旁边的“笔”图标进行编辑并输入新组合。按最后一个键将自动退出编辑模式并更改快捷键。

## 不可编辑的快捷键列表

某些快捷键只在&#x200B;**鼠标位于特定窗口**&#x200B;上方时&#x200B;**才有效**。

示例： **复制**&#x200B;和&#x200B;**粘贴**&#x200B;要求鼠标&#x200B;**位于图层堆叠上方**。

| *操作* | *快捷键(Windows)* | *快捷键(MacOS)* | 描述 |
| --- | --- | --- | --- |
| **复制图层** | Ctrl+C | ⌘+C | 复制当前选定的图层。 |
| **剪切图层** | Ctrl+X | ⌘+X | 剪切当前选定的图层。 |
| **粘贴图层** | Ctrl+V | ⌘+V | 将图层粘贴到内存中。 |
| **删除图层** | 删除 | 删除 | 删除当前选定的图层。 |
| **复制图层** | Ctrl+D | ⌘+D | 复制当前选定的图层。 |
| **对图层进行分组** | Ctrl+G | ⌘+G | 将当前选定的图层放入文件夹中。 |
| **复制图层内容** | Ctrl+Shift+C | Option+⌘+C | 复制图层内容（绘画）及其效果。 |
| **粘贴图层内容** | Ctrl+Shift+V | Option+⌘+V | 粘贴当前位于内存中的内容（绘画）和效果。 |
| **在视口中显示蒙版** | Alt +鼠标左键 | Option +鼠标左键 | 将视口显示模式切换到指定图层的蒙版。 |
| **禁用/启用蒙版** | Shift +鼠标左键 | Shift +鼠标左键 | 切换图层上蒙版的状态。 |
|  |  |  |  |
| **拖放材料** | 按住CTRL并拖放(&amp;D) | ⌘+拖放(&amp;D) | 按住此键的同时将材料（或智能材质）拖放到视口中可仅影响3D模型的特定部分。 |
|  |  |  |  |
| **操纵器约束/捕捉** | Shift | Shift | 在3D 视图中调整操纵器（平移或旋转）时捕捉变换。 在2D 视图中调整操纵器时约束比例。 |
| **镜像转换** | Ctrl | ⌘ | 镜像操纵器点围绕其2D 视图中心点进行变换。 |
