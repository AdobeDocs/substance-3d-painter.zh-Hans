# 显示设置

![](../../assets/display-settings-2.png){width="320px"}

**显示设置**&#x200B;窗口将环境、相机和视口设置重新分组。 这些设置是项目的全局设置，可能会影响视口的外观。

## 视图模式

![](../../assets/viewmode.png)

查看模式控制视口的外观。 该下拉菜单分为三个部分：

| 章节 | 描述 |
| --- | --- |
| **光照** | 在启用全光源（包括阴影）的情况下，在视口中显示3D模型。 |
| **单通道** | 也称为独奏模式。 在视口中只显示具有特定网格的通道或不带光照的纹理。 |
| **网格图** | 在视口中只显示具有特定烘焙纹理的网格，而不显示光照。 |

>[!NOTE]
>
> 还可以使用[视口](../../interface/viewport/viewport.md)边角处提供的<b>下拉菜单</b>更改查看模式。 还有[快捷键](../settings/shortcuts.md)可用于在声道、网格图之间快速循环，甚至可以返回到材质模式。
