# 管理图层

下面是图层栈叠中可能进行的操作：

| *操作* | *演示* |
| --- | --- |
| 单击并拖动以移动图层。 移动图层时，会显示一条条，指示图层的放置位置：<ul data-preserve-html="true"><li data-preserve-html="true"><strong>图层上方的条</strong> ：图层将置于该图层上方</li><li data-preserve-html="true"><strong>两个图层之间的条</strong> ：图层将放在两个图层之间</li><li data-preserve-html="true"><strong>图层下方的条</strong> ：图层将放在图层下方</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-above.gif"/></div> |
| **移至文件夹** ：单击并将图层悬停在文件夹上以将其放入其中 | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-folder.gif"/></div> |
| **多重选择** ：可通过两种不同的方式完成：<ul data-preserve-html="true"><li data-preserve-html="true">按住Ctrl或Command键</li><li data-preserve-html="true">按住Shift键并单击第一个和最后一个图层</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/dragdrop-ctrlselect.gif"/></div><div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid1_items_grid-cell_position-par_image" src="../../assets/dragdrop-shiftselect.gif"/></div> |
| **将图层分组** ：可通过以下操作之一用当前选定的图层创建文件夹：<ul data-preserve-html="true"><li data-preserve-html="true">右键单击>图层编组</li><li data-preserve-html="true">按Ctrl+G或Command+G</li></ul> | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/group-layer.gif"/></div> |
