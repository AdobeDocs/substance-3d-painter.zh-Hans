# Mac操作系统最新版本上的Nvidia GPU存在问题

在Mac OS下，Apple提供GPU驱动程序，方法是在GPU构造函数提供GPU驱动程序后对其进行验证。 自Mac使用Mojave操作系统以来，Apple尚未验证适用于最近Nvidia GPU的任何新驱动程序。 很遗憾，Substance 3D Painter需要最新的GPU驱动程序才能正常工作。

有关更多信息，请参阅以下页面：

* [Mac OS上支持的GPU列表](https://support.apple.com/en-us/HT208898) 。
* [在Mac OS上使用外部GPU](https://support.apple.com/en-us/HT208544) 。
