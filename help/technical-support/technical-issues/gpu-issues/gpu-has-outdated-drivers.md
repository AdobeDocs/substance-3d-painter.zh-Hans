# GPU具有过时的驱动程序

![](../../../assets/driver-outdated.png){width="500px"}

启动Substance 3D Painter时，可能会弹出窗口，指出GPU驱动程序已过时。 此消息仅表示该软件需要安装GPU驱动程序的最低版本。 我们建议尽可能将GPU驱动程序更新到最新版本，以获得最佳工作体验。

| *供应商* | *链接* |
| --- | --- |
| **NVIDIA** | [http://www.nvidia.com/Download/index.aspx](http://www.nvidia.com/Download/index.aspx?lang=en-us) <ul data-preserve-html="true"><li data-preserve-html="true"><strong> GeForce </strong> ：建议使用“Studio驱动程序”(SD)版本。</li><li data-preserve-html="true"><strong> Quadro </strong> ：建议使用“Optimal Driver for Enterprise” (ODE)版本。</li></ul> |
| **AMD** | <http://support.amd.com/en-us/download> |
| **英特尔** | <https://downloadcenter.intel.com/> |

>[!NOTE]
>
> 某些计算机<b>可能具有两个GPU</b>：集成的GPU（如Intel芯片组）和专用的GPU（如Nvidia显卡）。 <b>两个</b>都需要<b>为最新</b>以最大限度地降低Painter中出错的风险。
