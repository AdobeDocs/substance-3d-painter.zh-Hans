# 7.2更新后工具架资源消失

本页说明资源可能消失的原因以及如何恢复它们。

在更新到7.2版（或更高版本）后，工具架中的自定义资源（如alpha、滤镜、材料、智能材质甚至智能蒙版）可能已消失。 这是因为此新版本重置了首选项，且文件现在位于其他文件夹中。 仅忽略旧资源，可以通过手动复制文件来恢复旧资源。 为此，请查看[迁移指南](../../../pipeline-and-integration/resource-management/preferences-and-content-migration.md)。
