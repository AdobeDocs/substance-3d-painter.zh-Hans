# 错误：驱动器中没有磁盘

在Windows上，有时可能会遇到以下错误：

“驱动器中没有磁盘。 请在驱动器X中插入磁盘。”

![](../../../assets/disk-drive-error.png)

要解决此错误，需要检查以下几点：

* 验证您的驱动器号设置是否正确（请参阅<https://support.microsoft.com/en-us/kb/330137> ）
* 验证Substance 3D Painter中使用的所有以前位置是否有效（如“最近打开的文件”列表）
