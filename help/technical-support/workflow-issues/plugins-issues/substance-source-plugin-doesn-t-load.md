# Substance Source增效工具无法加载

出于技术和维护原因，Substance 3D Painter附带的Substance Source增效工具现已弃用。 本页说明如何删除它并提出替代解决方案。

* 自2020.1版(6.1.0)起，Substance 3D Painter不再包含该增效工具。
* 如果增效工具是使用旧版本安装的，则会保持安装状态。
* 由于插件不再更新，因此可能会停止工作。

## 替代

我们建议：

* **Substance Source**，可从以下网站下载材料： <https://www.substance3d.com/>
* **Substance启动器** ：可以使用“发送到”功能，通过专用Substance Source选项卡将素材发送到应用程序。

### 卸载

我们建议删除插件，因为它不再工作：

1. 转到您的&#x200B;**Documents/Allegorithmic/Substance 3D Painter/plugin**&#x200B;文件夹。
1. 选择并删除名为&#x200B;**substance-source**&#x200B;的文件夹。
1. 重新启动Substance 3D Painter。

>[!NOTE]
>
> 删除插件不会影响已下载到盘架中的内容。
