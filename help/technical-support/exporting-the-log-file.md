# 导出日志文件

本页介绍如何查找应用程序日志文件，以及如何共享该文件以请求支持。

## 正在检索日志文件

有两种获取日志文件的方法：

### 从应用程序导出日志文件

通过进入&#x200B;**帮助**&#x200B;菜单并选择&#x200B;**导出日志**&#x200B;操作，可以直接从应用程序导出日志文件。

![](../assets/screenshot-20210622-195334.png)

### 在磁盘上手动检索日志文件

如果应用程序未启动，则无法导出日志文件。 幸运的是，可以在磁盘上手动找到日志文件。 导航到下面与您的操作系统匹配的文件夹，然后手动检索&#x200B;**log.txt**&#x200B;文件。
