# 通过手动编辑首选项来添加资源路径

无需打开应用程序，即可添加其他自定义工具架或资源路径。

为此，需要编辑应用程序首选项（每个平台存储首选项的方式不同）。 添加后，新工具架应显示在主首选项的工具架列表中。 有关更多详细信息，请参阅此页面： [库配置](../../../interface/settings/libraries-configuration.md)

>[!NOTE]
>
> 不支持网络路径，请确保使用已装入的路径以避免任何问题。 请参阅： [从网络加载文件](../../../technical-support/workflow-issues/project-issues/loading-files-from-a-network.md)。
