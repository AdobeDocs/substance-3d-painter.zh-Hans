# 术语表

Substance 3D Painter是一款3D应用程序，它依赖于许多最初可能难以理解的技术和技术关键字。\
此页面列出了应用程序使用的最常用关键字及其背景概念的简短说明。

| *关键字* | *定义* |
| --- | --- |
| **对齐** | 对齐方式是画笔在绘画时面向3D网格的方向。 |
| **Alpha** | Alpha是一个蒙版，可用于绘制细节或复杂形状，例如条形码或徽标。 |
| **烘焙** | 烘焙是指根据网格的 UV 信息通过 3D 网格计算信息并将其保存到纹理中的操作。 |
| **位深度** | 位深度是能够存储在纹理中的信息量（每色）。 数目越多，信息精度越好。 但是，在进行计算时，如果数值较大，性能会降低。 |
| **画笔** | 笔刷是用于在网格上绘画的工具。 笔刷由控制其行为的多个参数（例如大小和不透明度）定义。 |
| **相机** | 相机是允许控制您在3D或2D视窗中观看的位置和方向的对象。 |
| **频道** | 通道是具有特定行为的纹理。 某些通道用于定义材质的颜色，其他通道用于控制曲面上的行为光照。 |
| **克隆** | 仿制是一种工具，用于在其他位置复制部分绘画/纹理。 |
| **内容/蒙版** | 内容和蒙版指的是图层的两个主要属性。 内容是存储在包含在图层中的通道中的实际绘画，而蒙版用于显示/隐藏内容。 黑色蒙版等于不可见内容。 |
| **扩散** | 扩散是一种在网格UV 岛之外生成信息的方式。 它的工作原理是对 UV 板块边界附近的最后一个像素进行渗透，从而产生模糊的颜色。 |
| **扩展/填充** | 与扩散算法一样，扩散算法也是通过扩展像素的UV 岛来生成颜色外部信息的一种方法。 |
| **效果** | 效果是指可以在图层上添加的元素，可以添加在内容或蒙版上。 Substance 3D Painter支持多种类型的效果，例如滤镜。 |
| **环境** | 环境是用于计算场景光照的图像，通常是一种HDR纹理，表示广泛的颜色信息。 |
| **导出** | 导出操作是从应用程序内实现的绘画中生成展平纹理的方法。 通过导出创建的纹理可用于其他应用程序。 |
| **FOV/视场** | FOV是摄像机可观测世界的范围。 |
| **填充** | 填充是一种操作（可以是效果或图层），可在整个3D网格上加载颜色、纹理甚至素材。 |
| **筛选器** | 过滤器是一种可修改以前信息的Substance效果。 例如，模糊滤镜将柔化上一张图像。 滤镜也可以更复杂，并修改全部素材。 |
| **筛选** | 过滤是指纹理在3D视口中的显示方式。 最常见的是最近（像素按原样读取，使图像看起来像块状，靠近）和双线性（像素插值，使图像看起来像模糊的靠近）。 |
| **GPU** | GPU（图形处理单元）是执行快速计算以产生图像的计算机的一部分。 |
| **生成器** | 生成器是一种Substance，通常基于其他纹理生成新的信息/图像。 例如，某些蒙版生成器使用烘焙纹理来创建复杂的蒙版。 |
| **直方图** | 直方图是颜色值分布的图形表示。 它用于将图像内部的阴影、中间色调和高光之间的颜色平衡进行可视化。 |
| **射线** | Iray是由NVIDIA创建的路径跟踪器渲染器，用于在3D网格上投射逼真的光照。 由于它是一个高级渲染器，因此它旨在创建漂亮的图像，而不是用于实时工作。 |
| **抖动** | 抖动是画笔的一个属性，用于在绘画时产生随机行为。 |
| **图层** | 图层是包含多个具有额外属性（如混合模式和不透明度）的通道的元素。 |
| **图层栈栈** | 图层栈栈是管理和组织图层的地方。 按从上到下的顺序整理图层。 首先画出底层，然后把上方的各层依次相加。 |
| **懒鼠** | 懒惰鼠标是画笔工具的行为。 它减慢画笔路径以提高绘画时的精度，在鼠标光标和实际绘画之间产生延迟/偏移。 |
| **级别** | 色阶是一种效果，允许通过直方图控制范围或颜色/灰度信息。 它可以用于反转颜色或调暗/调亮颜色。 |
| **日志** | 日志是一种文本文件，其中写入了来自软件的信息，通常与运行应用程序的计算机相关。 |
| **低/高多边形网格** | 一个是低密度的多边形，另一个是更高的多边形数量（通常是100倍大）。 通常，高网格信息会被烘焙到低网格。 |
| **材质** | 材质定义属性以表示特定事项。 在3D网格上，也可使用材料定义多边形面组。 |
| **网格** | 网格是由多个信息定义的3D对象。 在Substance 3D Painter中，网格由多边形（通常是三角形）定义。 可以在3D建模应用程序（如&#x200B;**Blender**&#x200B;或&#x200B;**Autodesk Maya**）中创建网格。 |
| **网格图** | 网格图是从网格生成的图，其中包含与网格相关的信息。 例如，可以是位置信息或遮蔽信息。 |
| **Mip-Map** | mip-map是预先计算的纹理，通常每次都以低于原始纹理的分辨率以图像序列的形式出现。 |
| **模式** | 模式是指界面的设置，可根据模式访问特定的一组工具和控件。 |
| **杂色** | 杂色是过程性和随机性的图像，通常表示有机形状和颜色/灰度值。 |
| **正常** | 法线是一种特殊的纹理，它使光线在3D网格表面上的行为方式变形，以模拟几何中不存在的细节。 |
| **OpenGL/DirectX** | OpenGL和DirectX都是用于渲染2D和3D信息的应用程序编程接口(API)。 它们还定义了法线贴图格式。 |
| **正交** | 正交投影是一种在二维中表示三维对象的装置，其中所有投影线都正交于投影平面。 |
| **PBR/PBS** | 基于物理的渲染(PBR)或基于物理的着色(PBS)是计算机图形学中的一个模型，旨在以更准确模拟现实世界中的光线流动的方式渲染图形。 |
| **打包** | 打包是将多张图像存储在一个纹理中的操作。 由于纹理是由单独的红色、绿色和蓝色通道组成的，因此它们可以存储不同的信息，以便在其他应用程序中独立读取。 |
| **粒子** | 粒子是一种基于物理属性或其他复杂行为生成画笔笔触的工具。 |
| **透视** | 透视是人眼在平面（如屏幕）上看到的对象或场景的近似表示。 这是对深度和规模的模拟。 |
| **像素/纹理** | 像素是图像中的点，是包含颜色信息的最小元素。 分辨率越大，可用的像素越多，清晰度越高，细节就越丰富。 纹理是纹理内的像素。 |
| **插件** | 插件是可以添加到软件中的编程功能（通常通过脚本表达），扩展了应用程序的可能性。 |
| **后期处理** | 后期处理是在渲染3D图像后在屏幕上应用的视觉效果，通常用于模拟特殊行为，如颜色校正或开花。 |
| **程序** | 过程是一个描述过程（由计算机根据一系列参数生成）的方法。 它可以是简单的数学结果，如数字或复杂图像。 |
| **投影** | 投影是从特定视角（如相机）将图像/对象应用于3D网格表面的操作。 |
| **分辨率（2的幂）** | 分辨率定义纹理在X轴和Y轴上的大小（或宽度和Height）。 通常采用2次方值(2， 4， 8， 16... 512， 1024， 2048...) 因为它针对GPU上的计算进行了优化。 |
| **脚本** | 脚本是通过基于文本的文件格式执行特定行为或使用特定命令的行为。 |
| **着色器** | 着色器定义材质在接收光照信息时的行为。 有些着色器可能简单（如卡通着色）或更高级（如模拟表面光线吸收的皮肤着色）。 |
| **托架** | 层架是应用程序中组织多种资源的地方。 它可以从简单的图像转变为更复杂的工具。 |
| **智能蒙版** | 智能蒙版的行为与智能素材类似，但它们的作用不是图层，而是定义为仅基于当前3D网格生成蒙版的效果。 |
| **智能素材** | 智能材质是另存为一个文件的一组图层。 智能素材可以适应Substance 3D Painter中的每个项目，允许创建根据当前3D网格而变化的素材。 |
| **涂抹** | 涂抹是一种用于渗色、扩散或混合颜色的工具。 它通常用于柔化像素。 |
| **模板** | 模板是对齐屏幕的图像，与相机投影配合使用可在3D网格上绘画。 |
| **Substance** | Substance是一种文件格式，它允许基于一组参数（涉及过程计算）生成纹理。 可以修改这些参数以创建变体。 |
| **对称** | 对称是工具的选项，允许在镜像中同时在两个位置绘画。 |
| **模板** | 模板是一组预定义选项，用于创建新项目。 例如，可以定义默认分辨率或默认烘焙设置。 |
| **文本比率** | 纹理比是比较UV 岛(2D)的大小和与之相关的3D网格的几何形状的规则。 良好的纹理比意味着几何形状在2D中的均匀展开。 这对于在3D网格上保持绘画/纹理效果的外观和质量一致非常重要。 |
| **纹理** | 纹理是包含分辨率定义的2维像素的文件。 像素可以是灰度或彩色。 着色时，像素可以包含透明度信息（如果文件格式支持此功能）。 |
| **纹理集** | 在Substance 3D Painter中，纹理集表示网格的一部分，该部分具有要绘制的特定UV。 纹理集是根据导入3D网格时检测到的独特素材创建的。 |
| **拼贴** | Tilling是纹理的重复，其中接缝在边界处不可见，它旨在模拟无限平面。 示例：草地或人行道。 |
| **工具** | 工具是指允许与3D网格交互（通常用于绘制或应用效果）的动作。 |
| **工具栏** | 工具栏是工具的所有图标快捷键都可用的位置。 |
| **UDIM** | UDIM是一种将3D网格的UV拆分到多个范围以提高常规纹理分辨率的方法。 |
| **UV** | UV是在3D网格上定义的信息，用于指示如何将其展开以变成平整形状。 此信息用于将纹理投影到3D网格上。 Substance 3D Painter只允许在0-1范围内绘画，该范围表示纹理的大小。 其它范围仅通过UDIM系统支持。 |
| **VRam** | VRam是GPU（显卡）的内存，用于在计算时存储信息和纹理。 vr越大，使用Substance 3D Painter的效果越好。 |
| **视区** | 视口是 3D 或 2D 场景在屏幕上显示的位置。 也可以通过控制相机来与工具和 3D 网格进行交互。 |
