# “导出”窗口

![](../../assets/export-textures-window.png){width="500px"}

使用<b>文件>导出纹理</b>或键盘快捷键<b>Ctrl + Shift + E</b>打开<b>导出窗口</b>。

<b>导出窗口</b>分为三个选项卡：

* [导出设置](export-settings.md)
* [输出模板](output-templates.md)
* [导出列表](list-of-exports.md)

窗口底部有多个按钮：

* <b>全部重置</b>（仅在<b>“设置”选项卡</b>上）：重置项目的导出配置。
* <b>取消</b>：关闭窗口，不保存任何更改。
* <b>保存设置</b>：将当前导出设置保存到项目中。
* <b>导出</b>：使用当前导出设置启动导出，并自动切换到<b>导出列表</b>部分以跟踪导出进度。
