# 输出模板

![](../../assets/preset-list.png)

Substance 3D Painter具有两种类型的输出模板，可用于控制导出过程的行为。

* [默认输出模板](default-presets.md)专用于处理特定的3D应用程序或工作流，可在<b>导出窗口</b>的<b>输出模板选项卡</b>中找到。 您可以复制和修改默认模板，也可以从头开始创建您自己的模板。
* 无法修改[预定义的输出模板](../../export/export-presets/predefined-presets/predefined-presets.md)。 预定义模板显示在<b>导出窗口</b>的<b>设置选项卡</b>上的<b>输出模板下拉列表</b>的顶部。
