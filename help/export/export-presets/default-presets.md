# 默认输出模板

以下是默认提供的其他输出模板列表。  可以在<b>导出窗口</b>的<b>输出模板选项卡</b>中复制和修改默认输出模板。

>[!NOTE]
>
> 可能还支持此处未列出的某些其他软件（如&#x200B;**辛烷**）。 有关详细信息，请参阅[生态系统和插件](https://experienceleague.adobe.com/zh-hans/docs/substance-3d/ecosystem/home)。

| *预设* | *描述* |
| --- | --- |
| <b> Amazon Lumberyard </b> | 命名要在Amazon Lumberyard中导入和使用的纹理，并将其打包。 |
| <b> Arnold (AiStandard) </b> | Arnold的预设(AiStandard着色器)。 |
| <b>旧版ArnoldUDIM(AiStandard)</b> | 旧版ArnoldUDIM(AiStandard)的预设。 |
| <b>混合器（原则性BSDF）</b> | 混合器的预设（原则性BSDF）。 |
| <b>电晕</b> | 电晕渲染器的预设。 |
| <b> CryEngine 3 </b> | 命名要在Cry引擎3中导入和使用的纹理并打包。 |
| <b> Dota 2 </b> | 游戏Dota 2的预设（可与相关模板一起使用）。 |
| <b>关键镜头</b> | 关键帧渲染器的预设。 |
| <b>关键帧9+</b> | 从版本9开始，关键帧渲染器的预设。 |
| <b>镜头工作室</b> | Lens Studio的预设（为Snapchat创建资源）。 |
| <b>Maxwell(金属粗糙度)</b> | 使用金属粗糙度工作流程的Maxwell渲染器预设。 |
| <b>Maxwell(光泽度)</b> | 使用光泽度工作流程的Maxwell渲染器预设。 |
| <b>个网格图</b> | 单独导出纹理集的烘焙网格图插槽（导出分辨率与纹理集相同）。 |
| <b>非PBR光泽度</b> | 为非PBR纹理工作流命名和导出光泽度。 |
| <b> PBR金属粗糙度</b> | 常规金属/粗糙度PBR纹理所需的名称和导出工作流。 |
| <b> PBR金属粗糙度（文件夹或PSD组） </b> | 与PBR MetalRough类似，但会创建一个额外的文件夹。 此预设主要适用于PSD文件格式。 |
| <b> PBR光泽度</b> | 常规Specular/光泽度PBR纹理所需的名称和导出工作流。 （纹理将通过“基色/金属”工作流程进行转换）。 |
| <b> PBR光泽度（从金属粗糙度</b>转换） | 转换“基色”、“金属”和“粗糙度”通道，使其与“Specular/彩色”工作流程兼容。 |
| <b> Redshift </b> | Redshift渲染器的预设。 |
| <b>Renderman (pxrDisney)</b> | 使用金属和粗糙度映射的渲染人预设。 |
| <b>Renderman (pxrSurface)</b> | 使用扩散和Specular映射的渲染器预设。 |
| <b>Roblox (MaterialVariant)</b> | Roblox预设使用反照率但没有Alpha支持。 |
| <b>Roblox (SurfaceAppearance)</b> | 将颜色映射与Alpha 通道结合使用，可实现Roblox的预设。 |
| <b>阴影3D </b> | 阴影3D的预设。 |
| <b>Spark AR Studio</b> | Spark AR Studio的预设。 |
| <b>Unity HD渲染管道（金属标准）</b> | 使用金属色和光泽度映射的Unity高清渲染管道预设。 |
| <b>Unity HD渲染管道(Specular)</b> | 添加了Specular映射的Unity HD渲染管道预设。 |
| <b>Unity通用渲染管道（金属标准）</b> | 使用金属和Smoothness映射的Unity通用渲染管道的预设。 |
| <b>Unity通用渲染管道(Specular)</b> | 使用Specular和Smoothness映射的Unity通用渲染管道的预设。 |
| <b>非真实引擎（打包） </b> | 以尽可能少的内存空间为虚构引擎中使用的名称和包纹理。 |
| <b>不实引擎SSS （打包）</b> | 以尽可能少的内存空间命名并打包要在虚构引擎中使用的纹理，用次表面散射替换不透明度图。 |
| <b> Vray Next (金属粗糙度)</b> | 使用PBR工作流程的视频渲染器预设。 |
| <b>Vray下一个(光泽度)</b> | 使用非PBR工作流程的视频渲染器预设。 |
| <b>旧版VrayUDIM(金属粗糙度)</b> | Vray渲染器的预设（UDIM命名约定）。 |
