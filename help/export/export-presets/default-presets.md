# 默认输出模板

以下是默认提供的其他输出模板列表。  可以在<b>导出窗口</b>的<b>输出模板选项卡</b>中复制和修改默认输出模板。

>[!NOTE]
>
> 可能还支持此处未列出的某些其他软件（如&#x200B;**辛烷**）。 有关详细信息，请参阅[生态系统和插件](https://experienceleague.adobe.com/en/docs/substance-3d/ecosystem/home)。

| *预设* | *描述* |
| --- | --- |
| <b> Amazon Lumberyard </b> | 在Amazon Lumberyard中命名和打包要导入和使用的纹理。 |
| <b> Arnold (AiStandard) </b> | Arnold（AiStandard着色器）的预设。 |
| <b> Arnold UDIM旧版(AiStandard)</b> | 旧版Arnold UDIM (AiStandard)的预设。 |
| <b>混合器（原则性BSDF）</b> | 混合器的预设（原则性BSDF）。 |
| <b>电晕</b> | 电晕渲染器的预设。 |
| <b> CryEngine 3 </b> | 命名和打包要在Cry Engine 3中导入和使用的纹理。 |
| <b> Dota 2 </b> | 游戏Dota 2的预设（可与相关模板一起使用）。 |
| <b>关键镜头</b> | 关键帧渲染器的预设。 |
| <b>关键帧9+</b> | 从版本9开始，关键帧渲染器的预设。 |
| <b>镜头工作室</b> | Lens Studio的预设（为Snapchat创建资源）。 |
| <b>麦克斯韦尔（金属粗糙度）</b> | 针对使用金属粗糙度工作流程的Maxwell渲染器的预设。 |
| <b>麦克斯韦尔（Specular光泽度）</b> | 使用Specular光泽度工作流程的Maxwell渲染器的预设。 |
| <b>网格映射</b> | 单独导出纹理集的烘焙网格映射槽（导出分辨率与纹理集的分辨率相同）。 |
| <b>非PBRSpecular光泽度</b> | 为非PBRSpecular光泽度工作流程命名和导出纹理。 |
| <b> PBR金属粗糙度</b> | 命名和导出常规金属/粗糙度PBR工作流程所需的纹理。 |
| <b> PBR金属粗糙度（文件夹或PSD组） </b> | 与PBR MetalRough类似，但会创建一个额外的文件夹。 此预设主要适用于PSD文件格式。 |
| <b> PBRSpecular光泽度</b> | 命名和导出常规Specular/光泽度PBR工作流程所需的纹理。 （纹理从“基色/金属质感”工作流程中转换）。 |
| <b> PBRSpecular光泽度（由金属粗糙度</b>转换） | 转换“基色”、“金属”和“粗糙度”通道，使其与“Specular/光洁度”工作流程兼容。 |
| <b> Redshift </b> | Redshift渲染器的预设。 |
| <b>Renderman (pxrDisney)</b> | 使用金属和粗糙度映射的Renderman的预设。 |
| <b>Renderman (pxrSurface)</b> | 使用扩散和Specular映射的渲染器预设。 |
| <b>Roblox (MaterialVariant)</b> | Roblox预设使用反照率但没有Alpha支持。 |
| <b>Roblox (SurfaceAppearance)</b> | 使用带有Alpha通道的颜色映射进行旋转扭曲预设。 |
| <b>阴影3D </b> | 阴影3D的预设。 |
| <b>Spark AR Studio</b> | Spark AR Studio的预设。 |
| <b>Unity HD渲染管道（金属标准）</b> | 使用金属色和光泽度映射的Unity高清渲染管道预设。 |
| <b>Unity HD渲染管道(Specular)</b> | 添加了Specular映射的Unity HD渲染管道预设。 |
| <b>Unity通用渲染管道（金属标准）</b> | 使用金属和Smoothness贴图的Unity通用渲染管道的预设。 |
| <b>Unity通用渲染管道(Specular)</b> | 使用Specular和Smoothness映射的Unity通用渲染管道的预设。 |
| <b>非实引擎（已打包） </b> | 以尽可能少的内存空间为虚设引擎中使用的名称和打包纹理。 |
| <b>不实引擎SSS （打包）</b> | 以尽可能低的内存空间命名和打包要在虚实引擎中使用的纹理，并用次表面散布代替不透明度贴图。 |
| <b> Vray Next （金属粗糙度）</b> | 使用PBR工作流程的视频渲染器预设。 |
| <b>下一帧（Specular光泽度）</b> | 使用非PBR工作流程的视频渲染器预设。 |
| <b>旧版Vray UDIM（金属粗糙度）</b> | 视频渲染器的预设（UDIM命名约定）。 |
