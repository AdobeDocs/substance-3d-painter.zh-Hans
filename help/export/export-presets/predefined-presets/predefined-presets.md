# 预定义的输出模板

无法编辑预定义的输出模板，它们由Substance 3D Painter本身生成。 预定义输出模板显示在<b>导出窗口</b>的<b>设置选项卡</b>上的<b>输出模板下拉列表</b>的顶部。

下表列出了不可编辑的可用预设：

* 2D View
* Document channels + Normal + AO（无Alpha）
* 文档通道+正常+ AO（带Alpha）
* Sketchfab
* Substance 3D Stager
* [USDz (Apple AR)](usd-pbr-metal-roughness-preset.md)
* glTF PBR金属粗糙度
* glTF PBR金属粗糙度+位移纹理（试验）
