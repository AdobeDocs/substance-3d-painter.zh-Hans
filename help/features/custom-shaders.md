# 自定义着色器

![](../assets/header-shader.jpg)

Substance Painter使用着色器在其实时视口中渲染材质。

可以编写自定义着色器以实现新行为，或简单地使视区与其他渲染器匹配。 在[Substance share](https://share.allegorithmic.com/libraries?by_category_type_id=6)上可以找到其他用于Substance Painter的着色器。

## 默认着色器

默认情况下，Substance Painter包括下列着色器：

无法渲染{children}。 未找到页面：默认着色器。

## 创建新着色器

只需创建新的&#x200B;**.glsl**&#x200B;文件，即可创建新的自定义着色器。

提供了详细的[着色器 API](https://helpx.adobe.com/cn/substance-3d/unlisted/documentation/spdoc/custom-shader-api-89686018.html)，并提供帮助函数以创建新效果并集成到现有工作流程中。
