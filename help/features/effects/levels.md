# 色阶

色阶是一种用于调整图像颜色范围的效果。 它允许平衡和色调颜色和/或灰度值。 您可以通过打开效果菜单来添加它：

![](../../assets/level-menu.png)

主界面显示一个直方图（界面中间的颜色山），它表示像素在每个颜色强度级别在图像中的分布方式。 直方图显示阴影（左侧部分）、中间色调（中间部分）和高光（右侧部分）的细节。 直方图还可快速查看颜色的色调范围，从而确定图像的暗度和亮度。

![](../../assets/image2015-3-20-11-24-24.png)

要调整图像的颜色范围，可以在直方图的顶部和底部使用两组控件：

* 三个顶部按钮控制阴影、中间色调和高光，并可用于重新分布色调范围以对比整个图像。
* 两个底部按钮控制图像的黑色和白场（通常是0和255）。 例如，这对于反转图像的颜色非常有用。

>[!NOTE]
>
> 如&#x200B;*受影响的通道*&#x200B;选项所选择，色阶效果一次只能应用于一个通道。 如果要将某个级别应用于多个通道，则必须创建多个级别效果。

* 通过右上角的颜色下拉框，可以更改整个rgb图像或仅红色、绿色和蓝色通道之一的色阶。
* 右下角的“夹紧”选项允许将色阶值夹在0和1 (0-255)之间。 在处理非HDR通道（如&#x200B;**基色**）时，应始终选中此选项。
