# 蒙版生成器

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_mask_builder_dark.png" alt=""/><strong>进入：</strong>蒙版，生成器</td>
    <td style="border: 0;" valign="top"><strong>说明</strong><br>蒙版生成器生成器是蒙版编辑器生成器的旧版本。 它是一个多用途蒙版生成器，可让您将污渍、AO、曲率、渐变、世界空间法线、Scratches、散点和微细节组合到单个蒙版中。<br><br>蒙版生成器生成器非常灵活，但由于其复杂性，与大多数生成器相比，它对性能的影响更大。<br><br>蒙版生成器生成器输出单色（黑白）纹理。 因此，它对于基于各种已烘焙贴图生成蒙版非常有用。 <br><br>图像输入需要烘焙位置、曲率、环境遮蔽和世界空间法线图。 <a href="../../../baking/baking.md">在此处了解有关烘焙的更多信息</a>。</td>
  </tr>
</table>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| **世界空间正常**&#x200B;颜色 | 使用烘焙过的世界空间法线图。 |
| **自定义污渍1**&#x200B;灰度 | 使用自定义纹理或锚点。 |
| **自定义污渍2**&#x200B;灰度 | 使用自定义纹理或锚点。 |
| **输入散点**&#x200B;灰度 | 使用自定义纹理或锚点。 |
| **位置**&#x200B;颜色 | 使用烘焙的位置图。 |
| **曲率**&#x200B;灰度 | 使用烘焙的曲率图。 |
| **环境遮蔽**&#x200B;灰度 | 使用烘焙的环境遮蔽图。 |
| **微正常**&#x200B;颜色 | 使用自定正常纹理或锚点。 |
| **微Height**&#x200B;颜色 | 使用自定义纹理或锚点。 |

### 垃圾摇滚

| 参数名称 | 描述 |
| --- | --- |
| **缩放** | 调整污渍纹理的大小。 |
| **使用自定义污渍** | 打开或关闭自定义污渍映射的使用。 只能看到自定义污渍1。 要控制自定义污渍2的可见性，请调整辅助自定义污渍滑块。 |
| **辅助自定义污渍** | 调整“自定义污渍2”纹理的可见性。 |
| **反转** | 反转污渍映射。 |

### 环境光遮蔽

| 参数名称 | 描述 |
| --- | --- |
| **范围** | 调整AO蒙版的范围。 |
| **对比度** | 调整AO蒙版的对比度/衰减。 |
| **杂色** | 向AO结果添加杂色，从而有效地降低蒙版的亮度。 |
| **反转** | 反转AO蒙版。 |

### 弯曲

| 参数名称 | 描述 |
| --- | --- |
| **凸范围** | 调整蒙版需要突出显示的最小凸角。 |
| **凸对比度** | 调整凸形蒙版对比度。 |
| **凸反转** | 反转凸形蒙版。 |
| **凹形范围** | 调整蒙版突出显示的最小凹角。 |
| **凹形对比度** | 调整凹形蒙版对比度。 |
| **凹反转** | 反转凹形蒙版。 |
| **Smoothness** | 调整“曲率”蒙版的亮区和暗区之间的混合。 |
| **水平提升** | 使用此选项可扩大蒙版区域的范围。 此函数类似于&#x200B;**凸范围**&#x200B;和&#x200B;**凹范围**&#x200B;参数的乘数。 |
| **杂色** | 向“曲率”结果添加杂色，从而有效地降低蒙版的亮度。 |

### 渐变

渐变位置基于位置图，该位置图可以用“完整场景”或“按材质”标准化比例进行烘焙。 如果您的素材仅出现在场景的一小块区域中，但位置地图使用完整的场景标准化比例烘焙，则可能很难调整渐变范围以获得所需的结果。

| 参数名称 | 描述 |
| --- | --- |
| **范围** | 调整渐变范围。 |
| **对比度** | 调整渐变对比度。 |
| **反转** | 反转渐变。 |

### 世界空间法线

**前**、**后**、**左**&#x200B;和&#x200B;**右**&#x200B;值可能与网格的前、后、左、右边不对应。 默认情况下，**前**&#x200B;对应于正X轴，右对应于正Z轴。

| 参数名称 | 描述 |
| --- | --- |
| **顶部强度** | 调整自上而下渐变的范围（强度）。 |
| **底部强度** | 调整由下而上渐变的范围（强度）。 |
| **前部强度** | 调整前后渐变的范围（强度）。 |
| **背部强度** | 调整前后渐变的范围（强度）。 |
| **右侧强度** | 调整左右渐变的范围（强度）。 |
| **左侧强度** | 调整左右渐变的范围（强度）。 |

### 划痕

| 参数名称 | 描述 |
| --- | --- |
| **金额** | 调整划痕的密度。 |
| **缩放** | 调整划痕的大小。 |

### 散点图

| 参数名称 | 描述 |
| --- | --- |
| **缩放** | 调整散点效果的大小。 比例越高，生成的图章就越多，越小，而比例越低，生成的个别图章大小就越大，可见图章就越少。 |
| **密度** | 调整散布图章的数量。 |
| **大小** | 调整散布图章的大小。 |
| **大小变化** | 调整散布图章的每个实例的大小有多大的随机性。 较大的“大小变化”会随机减小图章大小，因此，增大“大小变化”可能意味着您还需要增大“大小”值以保持相同的平均大小。 |
| **不透明度变化** | 调整散布图章的每个实例的不透明度中随机性的程度。 |
