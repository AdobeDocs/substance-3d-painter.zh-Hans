# 环境光遮蔽

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_ambient_occlusion.webp" alt=""/><br><strong>英寸：</strong>蒙版，生成器，灰度，混合</td>
    <td style="border: 0;" valign="top"><strong>描述</strong><br>环境遮蔽生成器会根据烘焙的环境遮蔽映射创建蒙版，并可以选择将纹理或微细节混合到蒙版中。<br><br>如果使用环境遮蔽生成器创建图层蒙版，可能需要反转环境遮蔽输出。 默认情况下，生成器将遮挡区域输出为暗区，并将未遮挡区域输出为亮区。 如果用作蒙版，被遮罩的图层仅在未遮住的区域中可见。 反转输出将确保蒙版图层仅出现在遮挡区域中。<br><br>需要烘焙位置、环境遮蔽和世界空间法线映射作为图像输入。 <a href="../../../baking/baking.md">在此处了解有关烘焙的更多信息</a>。</td>
  </tr>
</table>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| 纹理颜色 | 使用自定义纹理或锚点。 |
| 微标准色 | 使用自定正常纹理或锚点。 |
| 微Height颜色 | 使用自定义纹理或锚点。 |
| 环境遮蔽灰度 | 使用烘焙的环境遮蔽图。 |
| 世界空间法线颜色 | 使用烘焙过的世界空间法线图。 |
| 位置渐变颜色 | 使用烘焙的位置图。 |

## 参数

| 参数名称 | 描述 |
| --- | --- |
| **全局反转** | 合并所有效果后反转最终结果。 |
| **全局模糊** | 在合并所有效果后，均匀地平滑最终蒙版。 |
| **全局平衡** | 在黑色或白色之间组合所有效果后，改变最终蒙版的平衡，例如亮度调整。 |
| **全局对比度** | 在合并所有效果后调整最终蒙版的对比度。 |
| **使用纹理** | 打开或关闭自定义纹理贴图的使用。 |
| **使用微详细信息** | 打开或关闭自定义微细节的使用。 |

### 环境光遮蔽

| 参数名称 | 描述 |
| --- | --- |
| **反转** | 仅反转环境遮蔽和微细节。 |
| **模糊** | 仅平滑环境遮蔽和微细节。 |
| **余额** | 仅调整环境遮蔽和微细节的平衡，像亮度控制一样将中点向黑白方向移动。 |
| **对比度** | 仅调整环境遮蔽和微细节的对比度/衰减。 |

### 微细节

| 参数名称 | 描述 |
| --- | --- |
| **微型Height** | 打开或关闭自定义微Height映射的使用。 |
| **微普通** | 打开或关闭自定义微法线图的使用。 |
| **AO半径** | 在微观细节中调整环境遮蔽的半径（范围）。 |
| **AO深度** | 在微观细节中调整环境遮蔽的深度（强度）。 |
