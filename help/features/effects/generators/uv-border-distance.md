## 参数

| 参数名称 | 描述 |
| --- | --- |
| **反转** | 反转生成器输出。 |
| **余额** | 调整效果的平衡，像亮度控制一样将中点向黑白方向移动。 |
| **对比度** | 调整效果的对比度/衰减。 |
| **Smoothness** | 调整效果的圆度。 在使用低&#x200B;**Smoothness**&#x200B;值时，这是最可见的。 |
| **距离** | 调整效果向UV边框扩展的距离。 |
