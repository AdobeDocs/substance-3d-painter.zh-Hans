# UV 检测器

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_uv_checker.png" alt=""/><br><strong>进入：</strong> uv，边框，随机</td>
    <td style="border: 0;" valign="top"><strong>描述</strong><br>UV检查器生成器将类似于网格的检查器图案应用于模型，以便您能够轻松地发现UV问题，如拉伸、不均匀缩放或扭曲。 <br><br>UV检查器生成器通常直接用于填充图层上以查看UV扭曲。</td>

## 参数

<table>
  <tr>
    <th>参数名称</th>
    <th>描述</th>
  </tr>
  <tr>
    <td><strong>Seed</strong></td>
    <td>设置用于生成Dirt纹理的种子值。 <br><ul><li>单击“随机”可切换到另一个随机植入。</li><li>单击铅笔以查看当前种子值，并根据需要输入特定值。</li></ul></td>
  </tr>
  <tr>
    <td><strong>检查器颜色模式</strong></td>
    <td>选择如何分配颜色：<br><ul><li><strong>一致</strong>：对纹理集应用相同的颜色。</li><li><strong>随机</strong>：将随机颜色应用于每个UV 岛。</li></ul></td>
  </tr>
  <tr>
    <td><strong>检查器颜色</strong></td>
    <td>设置检查器图案的颜色。</td>
  </tr>
  <tr>
    <td><strong>检查器网格拼贴</strong></td>
    <td>调整检查器图案的大小。</td>
  </tr>
  <tr>
    <td><strong>检查器网格不透明度</strong></td>
    <td>调整网格的不透明度。 不透明度为0时，只显示检查器纹理，而不显示网格。</td>
  </tr>
  <tr>
    <td><strong>UV边框颜色</strong></td>
    <td>设置UV边框的颜色。</td>
  </tr>
  <tr>
    <td><strong>UV边框宽度</strong></td>
    <td>调整UV边框的宽度。</td>
  </tr>
</table>
