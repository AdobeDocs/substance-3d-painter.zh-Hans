## 描述

MatFinish颗粒状滤镜是金属光泽收藏集的一部分，用于创建颗粒状金属效果。

它用于填充图层。 调整基本填充图层的粗糙度、颜色、金属和其他属性，然后添加滤镜进行最终的表面处理。

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>位置：</b>颜色 | 使用烘焙的位置图。 |
| <b>世界空间法线：</b>颜色 | 使用烘焙的世界空间法线映射。 |

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>种子：</b> | 指定一个随机值，以在不更改整体设置的情况下创建不同的变化。 |
| <b>缩放：</b> | 调整抛光的整体比例。 |
| <b>颗粒强度：</b> | 调整颗粒强度。 |
| <b>三平面映射：</b> | 切换三平面映射。 |
