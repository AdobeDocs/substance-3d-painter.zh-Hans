## 描述

MatFinish拉丝线性滤镜是金属光饰收藏集的一部分，用于创建线性拉丝金属效果。

它用于填充图层。 调整基本填充图层的粗糙度、颜色、金属和其他属性，然后添加滤镜进行最终的表面处理。

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>种子：</b> | 指定一个随机值，以在不更改整体设置的情况下创建不同的变化。 |
| <b>缩放：</b> | 调整抛光的整体比例。 |
| <b>画笔强度：</b> | 调整画笔效果的强度。 |
| <b>长度：</b> | 调整画笔线条的长度。 |
| <b>旋转：</b> | 调整用画笔绘制的图案的旋转。 |
