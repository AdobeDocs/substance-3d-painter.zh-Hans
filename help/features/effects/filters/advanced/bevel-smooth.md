# 斜面平滑

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![斜面平滑图标](./Resources/icon_bevel_smooth.png "斜面平滑")

<b>入：</b>效果/斜面、平滑、距离、灰度

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

斜面平滑滤镜从蒙版边框向外或向内绘制渐变，或同时从两者绘制渐变。

它用于纹理图层或蒙版内（黑白输出），从蒙版边缘创建平滑的斜面渐变。

</td>
</tr>
</table>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>距离图：</b>灰度 | 使用自定义纹理或锚点。 |

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>方向：</b> | 选择应扩展的蒙版边框的一侧。 |
| <b>距离：</b> | 调整斜面膨胀的距离。 |
| <b>平滑：</b> | 调整应用于蒙版的平滑强度。 |
| <b>曲线偏移：</b> | 向内或向外调整蒙版边界。 |
| <b>曲线形状：</b> | 选择斜面斜率是使用挤压曲线还是圆角曲线。 |
| <b>蒙版阈值：</b> | 从输入中调整用于检测蒙版边界的值。 |
| <b>距离图乘数：</b> | 调整“最大距离”上距离图的影响。 |
| <b>斜面绕排：</b> | 切换斜角拼贴是水平还是垂直平铺。 |
