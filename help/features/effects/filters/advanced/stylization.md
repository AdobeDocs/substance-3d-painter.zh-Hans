## 描述

“风格化”滤镜为材料提供手绘、风格化的外观。

此效果可在纹理图层上用于添加绘画笔描边、Smoothness变化、颜色重映射和烘焙光照效果。

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>风格化：</b> | 调整滤镜的全局强度。 |
| <b>画笔描边：</b> | 调整画笔描边效果的整体强度。 |
| <b>Smoothness：</b> | 调整Smoothness效果的整体强度。 |
| <b>着色：</b> | 调整着色效果的整体强度。 |
| <b>渐变：</b> | 调整渐变效果的整体强度。 |
| <b>烘焙的光照：</b> | 调整烘焙光源效果的整体强度。 |
| <b>边缘和凹陷：</b> | 调整边缘和空腔效果的整体强度。 |

### 画笔描边

| 参数名称 | 描述 |
| --- | --- |
| <b>描边数量：</b> | 调整滤镜使用的画笔描边量。 |
| <b>描边模式：</b> | 选择滤镜使用的画笔描边类型。 |
| <b>描边选择：</b> | 选择使用多个描边时要投影的画笔描边形状。 |
| <b>描边选择：</b> | 选择在使用单个描边时要投影的画笔描边形状。 |
| <b>描边缩放：</b> | 调整画笔描边的比例。 |
| <b>非一致大小：</b> | 切换投影画笔描边的非均匀缩放。 |
| <b>描边大小：</b> | 调整投影的画笔描边的长宽比。 |
| <b>描边随机缩放：</b> | 调整应用于画笔描边的随机缩放变化量。 |
| <b>描边跟随表面：</b> | 将画笔描边的对齐方式切换到网格方向。 |
| <b>描边旋转：</b> | 调整画笔描边旋转角度。 |
| <b>笔触旋转随机：</b> | 调整应用于画笔描边的随机旋转量。 |
| <b>硬度：</b> | 调整图章投影的硬度。 |
| <b>正常阈值：</b> | 调整用于描边投影的正常阈值。 |

| 参数名称 | 描述 |
| --- | --- |

| <b>颜色随机：</b> | 调整应用于画笔描边的随机颜色变化量。 |
| <b>粗糙度自定义：</b> | 切换对画笔描边的自定义粗糙度值的使用。 |
| <b>粗糙度变化：</b> | 调整画笔描边的粗糙度变化。 |
| <b>粗糙度：</b> | 调整画笔描边的粗糙度值。 |
| <b>金属自定义：</b> | 在画笔描边上切换自定金属值的使用。 |
| <b>金属变体：</b> | 调整画笔描边的金属变化。 |
| <b>金属：</b> | 调整画笔描边的金属值。 |

| <b>垂直旋转：</b> | 调整渐变的垂直旋转。 |
