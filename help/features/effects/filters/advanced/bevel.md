## 描述

“斜面”滤镜将斜边添加到灰度形状和蒙版中。

它用于纹理图层或蒙版内（黑白输出），沿形状的边缘创建斜面浮雕。

</td>
</tr>

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>斜面绕排：</b> | 切换换行，使斜面平铺和垂直平铺。 |
| <b>距离：</b> | 调整斜角大小。 |
| <b>角类型：</b> | 选择斜角是圆角还是angular。 |
| <b>平滑：</b> | 调整应用于斜角的平滑量。 由于曲线存在锯齿，如果不进行任何平滑处理，曲线斜角可能会出现明显的条纹。 |
| <b>模糊模式：</b> | 选择斜角是使用均匀还是非均匀模糊。 非均匀模糊将模糊效果聚焦在斜面区域，这有助于保持细节，但均匀模糊更加一致。 |
