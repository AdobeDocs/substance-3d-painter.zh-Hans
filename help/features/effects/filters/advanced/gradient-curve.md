## 描述

“渐变曲线”滤镜通过可自定义的渐变曲线重新映射值。

它用于纹理图层或蒙版内（黑白输出），以将灰度值重新映射到预设曲线形状。

</td>
</tr>

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>预设：</b> | 选择曲线预设。 |
| <b>反转：</b> | 切换结果的反转。 |
| <b>余额：</b> | 调整黑白结果之间的平衡，类似于亮度调整。 |
| <b>对比度：</b> | 调整结果的对比度或衰减。 |
