## 描述

三平面高级滤波器是三平面高级发生器的滤波器版本，整个投影采用手动控制。 通过它，可控制每个轴的旋转值和偏移值。 与生成器不同，此滤镜直接作用于图层内容，而生成器需要自定义蒙版输入才能进行混合。

该图层可在纹理图层上或蒙版内部使用，以添加三平面混合。

</td>
</tr>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>世界空间法线：</b> | 使用烘焙的世界空间法线映射。 |
| <b>位置：</b> | 使用烘焙的位置图。 |

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>投影：</b> | 选择要跨哪些轴进行投影。 |
| <b>混合模式：</b> | 选择投影混合的方式。 |
| <b>混合对比度：</b> | 调整投影混合的对比度。 |
| <b>拼贴：</b> | 调整投影纹理的拼贴。 |
| <b>旋转X：</b> | 调整X投影的旋转。 |
| <b>偏移X：</b> | 调整X投影的偏移。 |
| <b>旋转Y：</b> | 调整Y投影的旋转。 |
| <b>偏移Y：</b> | 调整Y投影的偏移。 |
| <b>旋转Z：</b> | 调整Z投影的旋转。 |
| <b>偏移Z：</b> | 调整Z投影的偏移。 |

### 轴X

| 参数名称 | 描述 |
| --- | --- |
| **旋转X：** | 调整X纹理投影的旋转。 |
| **偏移X X：** | 调整X轴沿X轴的X投影偏移。 |
| **偏移X Y：** | 调整X轴沿Y轴的投影偏移。 |

>[!NOTE]
>
> 偏移参数在其标题中包含两个轴。 第一个定义轴，第二个定义偏移轴。 因此，**偏移X Y**&#x200B;专门查看X轴上的投影，并沿投影局部Y轴偏移该投影。
>
>对此的另一个思路是&#x200B;**偏移X X**&#x200B;使X投影&#x200B;**水平**&#x200B;偏移，**偏移X Y**&#x200B;使X投影&#x200B;**垂直**&#x200B;偏移。

### 轴Y

| **偏移Y X：** | 调整Y轴沿X轴的投影偏移。 |
| **偏移Y：** | 调整Y轴沿Y轴的投影偏移。 |

>[!NOTE]
>
> 偏移参数在其标题中包含两个轴。 第一个定义轴，第二个定义偏移轴。 因此，**偏移Y X**&#x200B;专门查看Y轴上的投影，并沿投影局部X轴偏移该投影。
