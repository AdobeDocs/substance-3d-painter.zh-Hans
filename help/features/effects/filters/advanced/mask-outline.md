# 蒙版轮廓

<td width="33.33%" style="border: 0;" valign="top">

<b>范围：</b>效果/滤镜、灰度、蒙版

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

蒙版轮廓滤镜从蒙版的边缘创建轮廓。

它用于纹理图层或蒙版内部（黑白输出），以在蒙版形状周围生成内部、外部或双轮廓。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>蒙版位置：</b> | 选择轮廓是出现在蒙版边缘的外部、内部还是两侧。 |
| <b>从黑色开始：</b> | 切换大纲是否从黑色开始。 这有效地起到一种反转开关的作用。 |
| <b>阈值：</b> | 调整用于检测蒙版边缘的阈值。 |
| <b>宽度：</b> | 调整轮廓的宽度。 |
| <b>模糊：</b> | 调整应用于轮廓的模糊。 |
| <b>曲线形状：</b> | 调整轮廓衰减的形状。 |
