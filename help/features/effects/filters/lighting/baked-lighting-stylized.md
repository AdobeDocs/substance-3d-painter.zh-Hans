## 描述

“烘焙光照风格化”滤镜将材料和光照信息烘焙到颜色通道中。

它用于设置为直通模式的绘画图层并应用于所有通道。 对于风格化工作流程，其中不需要准确的模拟光照或资源有限时（例如，在移动项目上或仅依赖颜色图的资源上），此选项很有用。

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>Ambient occlusion：</b>灰度 | 使用烘焙的Ambient occlusion映射。 |
| <b>弯曲：</b>灰度 | 使用弯曲图。 |
| <b>正常：</b>颜色 | 使用法线图。 |
| <b>世界空间法线：</b>颜色 | 使用烘焙的世界空间法线映射。 |

### 材质

| 参数名称 | 描述 |
| --- | --- |
| **介电反射率：** | 设置介电反射量。 |
| **DiffuseAO：** | 控制ambient occlusion对漫射细节的影响程度。 |
| **Diffuse空腔：** | 控制腔面积对漫射细节的影响程度。 |
| **SpecularAO：** | 控制ambient occlusion对Specular细节的影响程度。 |
| **Specular空腔：** | 调整腔面积对Specular细节的影响程度。 |
| **空腔Smoothness：** | 调整空洞区域的平滑程度。 |
| **边缘强度：** | 设置边缘细节的强度。 |
| **边缘Smoothness：** | 调整边缘区域的Smoothness。 |
| **正常详细信息类型：** | 选择哪些详细信息用于法线：仅网格或网格+Height+法线。 |
| **Height为正常强度：** | 调整生成的正常细节的强度。 |
