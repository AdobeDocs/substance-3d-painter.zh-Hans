## 描述

MatFX Comic Book滤镜以漫画书为灵感使材料风格化。

它用于纹理层，以简化的着色和加粗的视觉处理来创建图形、插图的渲染样式。

</td>
</tr>
</table>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>Ambient occlusion：</b>灰度 | 使用烘焙的ambient occlusion映射。 |
| <b>弯曲：</b>灰度 | 使用弯曲图。 |

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>输入类型：</b> | 选择效果使用的输入类型。 |
| <b>输入对比度：</b> | 调整输入的对比度。 |
| <b>输入明度：</b> | 调整输入的明度。 |
| <b>颜色强度：</b> | 调整颜色处理的强度。 |
| <b>边框不透明度：</b> | 调整边框的不透明度。 |
| <b>边框容差：</b> | 调整边界检测容差。 |
| <b>边框Smoothness：</b> | 调整边框Smoothness。 |
| <b>绘画强度：</b> | 调整绘画效果的强度。 |
| <b>变形：</b> | 调整变形效果。 |
| <b>锐度：</b> | 调整结果的锐度。 |
| <b>输出对比度：</b> | 调整输出的对比度。 |
| <b>输出明度：</b> | 调整输出的明度。 |
