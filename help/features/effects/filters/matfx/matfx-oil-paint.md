## 描述

MatFX油绘画滤镜通过油绘画外观风格化源。

它用于纹理图层，以描绘出受油画绘画启发的绘画描边、颜色变化和表面细节。

<a name="parameters"></a>

## 参数

**预设**&#x200B;可用，可以快速更新滤镜中的多个其他参数作为起点。

>[!NOTE]
>
> 选择预设后，它会将所有参数设置为预设值 — 如果您对滤镜进行了不想丢失的更改，则值得创建滤镜的副本并在尝试预设之前切换可见性。

| 参数名称 | 描述 |
| --- | --- |
| <b>输入类型：</b> | 选择效果使用的输入类型。 |
| <b>效果强度：</b> | 调整效果的整体强度。 |
| <b>精细细节：</b> | 调整结果中保留的精细细节量。 |
| <b>锐度：</b> | 调整结果的锐度。 |
| <b>粗糙度：</b> | 调整粗糙度值。 |
| <b>粗糙度变化：</b> | 调整结果中的粗糙度变化。 |
| <b>粗糙度详细信息：</b> | 调整细节对粗糙度的影响。 |
| <b>正常强度：</b> | 调整常规效果的强度。 |
| <b>正常描边方向影响：</b> | 调整描边方向对正常结果的影响程度。 |
