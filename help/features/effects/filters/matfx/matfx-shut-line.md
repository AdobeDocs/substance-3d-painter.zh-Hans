## 描述

MatFX“关闭行”滤镜在材料上创建面板行或接缝详细信息。

它用于纹理图层或材料堆叠，可添加闭合线、浮雕接缝以及支持Height和颜色细节。

</td>
</tr>

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>空腔宽度：</b> | 调整腔体的宽度。 |
| <b>斜率强度：</b> | 调整斜率效果的强度。 |
| <b>强度：</b> | 调整浮雕的强度。 |
| <b>Height强度：</b> | 调整Height效果的强度。 |

### 材质

| 参数名称 | 描述 |
| --- | --- |
| <b>线条颜色：</b> | 调整线条颜色。 |
| <b>源材料不透明度：</b> | 调整源材料的不透明度。 |
