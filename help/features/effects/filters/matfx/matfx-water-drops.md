# MatFX水滴

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

MatFX水滴滤镜可在材料上创建水滴和径流效果。

它用于纹理图层或材料堆叠以添加水滴、定向条纹和湿表面变化。

</td>
</tr>
</table>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>Ambient occlusion：</b>灰度 | 使用烘焙的ambient occlusion映射。 |
| <b>世界空间法线：</b>颜色 | 使用烘焙的世界空间法线映射。 |
| <b>位置：</b>颜色 | 使用烘焙的位置图。 |

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>丢弃数量：</b> | 调整水滴的数量。 |
| <b>丢弃缩放X：</b> | 调整液滴的X比例。 |
| <b>丢弃缩放Y：</b> | 调整液滴的Y比例。 |
| <b>丢弃随机缩放：</b> | 调整液滴中的随机缩放变化量。 |
| <b>降低方向强度：</b> | 调整水滴的定向强度。 |

### 位置

| 参数名称 | 描述 |
| --- | --- |
| <b>影响X：</b> | 调整位置输入的X影响。 |
| <b>影响Y：</b> | 调整位置输入的Y影响。 |
| <b>影响Z：</b> | 调整位置输入的Z影响。 |

### 蓄水

| 参数名称 | 描述 |
| --- | --- |
| <b>强度：</b> | 调整积水的强度。 |
| <b>跨页：</b> | 调整积水的扩散。 |
| <b>基于AO的强度：</b> | 调整ambient occlusion对水积累的影响程度。 |

### 世界空间

| 参数名称 | 描述 |
| --- | --- |
| <b>蒙版强度：</b> | 调整世界空间蒙版的强度。 |
| <b>顶部强度：</b> | 调整面向上方的区域上的液滴强度。 |
| <b>底部强度：</b> | 调整面向下方的区域上的液滴强度。 |
| <b>前部强度：</b> | 调整正面区域的液滴强度。 |
| <b>背部强度：</b> | 调整背面区域的液滴强度。 |
| <b>右侧强度：</b> | 调整面向右侧区域的液滴强度。 |
| <b>左侧强度：</b> | 调整左向区域的液滴强度。 |

### 材质

| 参数名称 | 描述 |
| --- | --- |
| <b>降低Base color变形强度：</b> | 调整应用于液滴下方的base color的变形强度。 |
| <b>删除旋转矢量映射乘数：</b> | 调整应用于放置旋转矢量图的乘数。 |
| <b>降低Height强度：</b> | 调整投影Height效果的强度。 |
| <b>删除粗糙度：</b> | 调整液滴的粗糙度。 |
| <b>删除粗糙度混合：</b> | 调整投影粗糙度与材料混合的方式。 |
| <b>删除金属：</b> | 调整液滴的金属值。 |
| <b>丢弃金属混合：</b> | 调整投影金属值与材料混合的方式。 |
| <b>正常强度：</b> | 调整常规效果的强度。 |
