## 描述

MatFX风化过滤器可创建整个材料的铁锈构建和风化。

它用于纹理层或材料堆叠以添加腐蚀、滴落和老化风化效果。

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>模糊强度：</b> | 调整模糊效果的强度。 |
| <b>模糊绕排：</b> | 启用或禁用模糊绕排。 模糊绕排打开时，从纹理的另一侧取样像素。 |
| <b>铁锈分配：</b> | 调整铁锈扩散。 |
| <b>正在分配Smoothness：</b> | 调整扩展Smoothness。 |
| <b>清漆破损等级：</b> | 调整清漆破损等级。 |
| <b>液滴强度：</b> | 调整液滴强度。 |
| <b>滴样量：</b> | 调整滴样量。 |
| <b>滴Smoothness：</b> | 调整滴Smoothness。 |

### 混合

| 参数名称 | 描述 |
| --- | --- |
| <b>正常强度：</b> | 调整法线图混合强度。 |
| <b>Ambient occlusion强度：</b> | 调整AO映射混合强度。 |
| <b>Height强度：</b> | 调整高度图混合强度。 |

**金属粗糙度**

| 参数名称 | 描述 |
| --- | --- |
| <b>Base color强度：</b> | 调整base color强度。 |
| <b>粗糙度强度：</b> | 调整粗糙度图混合强度。 |
| <b>金属强度：</b> | 调整金属映射混合强度。 |
