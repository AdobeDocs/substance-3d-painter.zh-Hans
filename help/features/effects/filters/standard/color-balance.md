## 描述

“色彩平衡”滤镜对高光、中间色调和阴影进行细微更改。

可在填充图层上使用它进行细微的颜色调整。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

### 高光

<table>
<tr>
<td><b>青色&lt;-&gt;红色：</b></td>
<td>将颜色向青色或红色偏移。</td>
</tr>
<tr>
<td><b>洋红&lt;-&gt;绿色：</b></td>
<td>将颜色朝洋红色或绿色移动。</td>
</tr>
<tr>
<td><b>黄&lt;-&gt;蓝：</b></td>
<td>将颜色向黄色或蓝色偏移。</td>
</tr>
</table>
