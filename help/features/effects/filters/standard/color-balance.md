## 描述

“色彩平衡”滤镜对高光、中间色调和阴影进行细微更改。

可在填充图层上使用它进行细微的颜色调整。

</td>
</tr>

<a name="parameters"></a>

## 参数

### 高光

| 参数名称 | 描述 |
| --- | --- |
| **青色&lt;->红色：** | 将颜色向青色或红色偏移。 |
| **洋红&lt;->绿色：** | 将颜色朝洋红色或绿色移动。 |
| **黄色&lt;->蓝色：** | 将颜色向黄色或蓝色偏移。 |

### 中间调

| 参数名称 | 描述 |
| --- | --- |
| **青色&lt;->红色：** | 将颜色向青色或红色偏移。 |
| **洋红&lt;->绿色：** | 将颜色朝洋红色或绿色移动。 |
| **黄色&lt;->蓝色：** | 将颜色向黄色或蓝色偏移。 |

### 阴影

| 参数名称 | 描述 |
| --- | --- |
| **青色&lt;->红色：** | 将颜色向青色或红色偏移。 |
| **洋红&lt;->绿色：** | 将颜色朝洋红色或绿色移动。 |
| **黄色&lt;->蓝色：** | 将颜色向黄色或蓝色偏移。 |
