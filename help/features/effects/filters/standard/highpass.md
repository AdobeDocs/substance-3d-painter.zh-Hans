## 描述

高反差滤镜执行高反差滤镜效果，类似于具有相同名称的Photoshop操作。 它可用于消除图像中的大明亮度差异，例如在清理纹理以进行拼贴时。

它用于纹理图层或遮罩层，以移除较大的明亮度差异。

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>色彩空间：</b> | 选择滤镜使用的色彩空间。 |
| <b>半径：</b> | 调整高反差半径。 |
| <b>应用于Alpha：</b> | 切换筛选器是否影响Alpha 通道。 |
