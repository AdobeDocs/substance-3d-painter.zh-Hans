## 描述

投影滤镜将创建投影。

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>角度：</b> | 调整阴影角度。 |
| <b>距离：</b> | 调整阴影距离。 |
| <b>大小：</b> | 调整阴影大小。 |
| <b>跨页：</b> | 调整阴影的扩散。 |
| <b>不透明度：</b> | 调整阴影不透明度。 |
| <b>颜色：</b> | 调整阴影颜色。 |
