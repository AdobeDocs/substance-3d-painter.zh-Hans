## 描述

“发光”滤镜在输入的可见部分周围创建外发光。

该功能可在纹理图层上或蒙版内（黑白输出）使用，以在形状和材料周围添加柔和或精确的光晕。

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>用于蒙版：</b> | 切换是否在蒙版上使用发光。 |
| <b>模式：</b> | 选择发光是使用“柔和”模式还是“精确”模式。 |
| <b>宽度：</b> | 调整发光宽度。 |
| <b>跨页：</b> | 调整发光范围。 |
| <b>不透明度：</b> | 调整发光的不透明度。 |
| <b>颜色：</b> | 调整发光颜色。 |
