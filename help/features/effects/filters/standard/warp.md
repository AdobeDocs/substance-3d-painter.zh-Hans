<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>进入：</b>效果/灰度

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

变形滤镜用于各种变形效果。 变形滤镜提供对常规变形、在特定方向变形的定向变形和多方向变形的访问，以实现更多变化。

可在纹理图层上或蒙版内（黑白输出）使用变形来变形材料、形状、蒙版、轮廓等。

</td>
</tr>
</table>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>自定义噪声</b> | 使用自定义纹理作为噪声输入图。 |

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>种子：</b> | 指定一个随机值，以在不更改整体设置的情况下创建不同的变化。 |
| <b>变形模式：</b> | 选择变形模式。 |
| <b>强度：</b> | 调整变形强度。 |
| <b>强度分隔线：</b> | 选择变形强度的划分方式。 |
| <b>角度：</b> | 调整变形角度。 |
| <b>混合模式：</b> | 选择变形使用的混合模式。 |
| <b>方向：</b> | 选择变形方向的数量。 |

### 源参数

<table>
<tr>
<td><b>源模式：</b></td>
<td>确定源模式。<br><br>  — 默认噪声：使用默认噪声作为变形效果。<br>  — 上一个输入：使用上一个输入获得变形效果。 当填充图层应用了特定的噪声模式时，在“上一输入”模式下使用变形效果将导致效果使用与填充图层相同的噪声模式。<br>  — 自定噪声：使用自定噪声输入获得变形效果。</td>
</tr>
<tr>
<td><b>源模糊：</b></td>
<td>模糊源噪声。</td>
</tr>
<tr>
<td><b>源余额：</b></td>
<td>调整源噪声的平衡，像亮度控制一样将中点向黑白方向移动。</td>
</tr>
<tr>
<td><b>源对比度：</b></td>
<td>微调源噪声的对比度。</td>
</tr>
<tr>
<td><b>Source Tilling：</b></td>
<td>控制源噪声的拼贴。</td>
</tr>
</table>
