## 描述

“色彩校正”滤镜调整高光、中间色调和阴影的更改。

此工具用于填充图层，可细微调整对比度、亮度和饱和度。

## 参数

### 阴影

| 参数名称 | 描述 |
| --- | --- |
| **对比度：** | 调整阴影的对比度。 |
| **明度：** | 调整阴影的亮度。 |
| **饱和度：** | 调整阴影的饱和度。 |

### 中间调

| 参数名称 | 描述 |
| --- | --- |
| **对比度：** | 调整中间调的对比度。 |
| **明度：** | 调整中间色调的亮度。 |
| **饱和度：** | 调整中间调的饱和度。 |

### 高光

| 参数名称 | 描述 |
| --- | --- |
| **对比度：** | 调整高光的对比度。 |
| **明度：** | 调整高光的亮度。 |
| **饱和度：** | 调整高光的饱和度。 |
