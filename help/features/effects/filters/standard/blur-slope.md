    <td style="border: 0;" valign="top">说明<br>斜率模糊滤镜可产生涂抹或渐隐效果，特别适用于颜色之间的高对比度边缘。<br>它可以直接在纹理图层上用于模糊整个材料或特定纹理，或用于蒙版上用于涂抹蒙版。 它可以创建诸如破损边缘或风化边缘、泄漏Dirt或涂抹铁锈之类的效果。</td>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| **自定义噪声：**&#x200B;灰度 | 使用自定义纹理或锚点作为自定义噪声。 |

## 参数

| 参数名称 | 描述 |
| --- | --- |
| **种子：** | 指定一个随机值，以在不更改整体设置的情况下创建不同的变化。 |
| **强度：** | 调整模糊强度。 |
| **强度分隔线：** | 选择如何划分模糊强度。 |
| **混合模式：** | 选择斜率模糊使用的混合模式。 |
| **质量：** | 调整效果的质量。 |

### 源参数

| 参数名称 | 描述 |
| --- | --- |
| **源类型：** | 选择源是使用默认噪声、上一次输入还是自定义噪声。 |
| **模糊：** | 调整源噪声或输入的模糊强度。 |
| **位置：** | 调整源噪声或输入的中点，类似于亮度控制。 |
| **对比度：** | 调整源噪声或输入的对比度。 |
| **源拼贴：** | 调整源噪声或输入的拼贴。 |
