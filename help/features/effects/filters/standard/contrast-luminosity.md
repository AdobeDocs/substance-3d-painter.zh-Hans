## 描述

对比度亮度滤镜是一种简单的对比度和亮度（亮度）调整。

它可以直接用于填充图层，也可以用于蒙版（黑白输出），用于微调对比度和明度（亮度）。

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>对比度：</b> | 调整结果的对比度/衰减。 |
| <b>明度：</b> | 调整明度。 |
