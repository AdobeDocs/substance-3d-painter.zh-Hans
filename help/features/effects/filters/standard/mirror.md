## 描述

镜像滤镜是一个用于复制部分输入的对称滤镜。

它用于纹理图层（颜色）或蒙版，以根据镜像轴镜像完整的材料、蒙版、形状等。

</td>
</tr>
</table>

>[!NOTE]
>
> 镜像滤镜在UV空间中工作，因此在&#x200B;**视口**&#x200B;中打开2D 视图可能很有用。

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>显示调试：</b> | 切换调试视图的显示。 |
| <b>模式：</b> | 选择镜像模式。 |
| <b>轴X偏移：</b> | 调整X轴偏移。 |
| <b>轴Y偏移：</b> | 调整Y轴偏移。 |
| <b>反转轴X：</b> | 在X轴上切换反转。 |
| <b>反转轴Y：</b> | 在Y轴上切换反转。 |
| <b>角类型：</b> | 选择如何处理镜像转角。 |
