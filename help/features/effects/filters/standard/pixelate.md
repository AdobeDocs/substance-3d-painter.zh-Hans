## 描述

“像素化”滤镜将输入转换为大块以模拟像素化外观。

它用于纹理图层（颜色）或蒙版以将完整的材料、噪声、蒙版、形状等像素化。

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>像素数量：</b> | 调整像素数，这会产生更改像素大小的副作用。 像素越多，像素越小。 |
| <b>应用于Alpha：</b> | 切换筛选器是否也修改Alpha 通道。 |
