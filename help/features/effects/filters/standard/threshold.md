## 描述

对于与阈值相关的输入像素值，当在Mode参数中设置的比较标准满足时，“阈值”过滤器将返回白色。 它类似于直方图扫描，但对比度始终位于其最高水平，从而提供更快、更准确的方式来获得类似结果。

它可以直接用于填充图层或蒙版（黑白输出），从特定通道快速创建高对比度蒙版。

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>阈值：</b> | 调整与输入像素值比较的明亮度值。 |
| <b>模式：</b> | 选择用于阈值的比较标准：大于、大于或等于、小于或小于或等于。 |
| <b>_mode：</b> | 选择内部模式值。 |
| <b>_threshold：</b> | 调整内部阈值。 |
| <b>_threshold_min：</b> | 调整内部最小阈值。 |
| <b>_threshold_max：</b> | 调整内部最大阈值。 |
