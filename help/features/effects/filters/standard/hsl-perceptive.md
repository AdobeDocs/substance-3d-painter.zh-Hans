## 描述

HSL可感知滤镜调整色相、饱和度和明亮度。

它用于纹理图层（颜色）以调整色相、饱和度和明亮度。

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>模式：</b> | 选择HSL调整模式。 **可感知**&#x200B;根据我们感知颜色的方式调整值，而&#x200B;**常规**&#x200B;根据计算机内部呈现颜色的方式进行调整。 |
| <b>色相：</b> | 调整色相。 |
| <b>饱和度：</b> | 调整饱和度。 |
| <b>明亮度：</b> | 调整明亮度。 |
