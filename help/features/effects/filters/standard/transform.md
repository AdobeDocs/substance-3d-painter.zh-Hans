<b>进入：</b>效果/变换

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

“变换”滤镜用于变换（缩放、旋转、偏移）图层。

该图层可在纹理图层上或蒙版内（黑白输出）使用，例如变换图案、形状等。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>重复模式：</b> | 选择重复模式。 |
| <b>翻转模式：</b> | 选择翻转模式。 |
| <b>缩放X：</b> | 调整结果的X缩放比例。 |
| <b>缩放Y：</b> | 调整结果的Y缩放比例。 |
| <b>偏移X：</b> | 调整结果的X偏移量。 |
| <b>偏移Y：</b> | 调整结果的Y偏移。 |
| <b>磁贴安全旋转：</b> | 切换拼贴安全旋转。 |
| <b>旋转：</b> | 调整旋转。 |
| <b>缩放：</b> | 调整整体缩放比例。 |
| <b>偏移：</b> | 调整整体偏移。 |
