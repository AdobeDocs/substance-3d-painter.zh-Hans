## 描述

“渐变”滤镜使用自定义渐变重新映射图像中的灰度值。

它可以用于调整灰度图像的值，或通过将其映射到自定义渐变来为灰度输入上色。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>显示渐变（调试）：</b> | 切换渐变调试视图的显示。 |
| <b>颜色数量：</b> | 调整渐变中使用的颜色数量。 |
| <b>线性中的混合颜色：</b> | 切换线性颜色混合。 |
| <b>颜色1：</b> | 选择第一种颜色。 |
| <b>颜色1位置：</b> | 调整第一种颜色的位置。 |
| <b>颜色2：</b> | 选择第二种颜色。 |
| <b>颜色2位置：</b> | 调整第二种颜色的位置。 |
| <b>颜色N：</b> | 选择第N种颜色。 |
| <b>颜色N位置：</b> | 调整第N种颜色的位置。 |

### 输入转换

<table>
<tr>
<td><b>灰度模式：</b></td>
<td>选择灰度变换模式。 可以在饱和度降低、亮度、平均值、最大值和最小值之间进行选择。</td>
</tr>
<tr>
<td><b>模糊强度：</b></td>
<td>调整输入被模糊的程度。</td>
</tr>
<tr>
<td><b>平衡：</b></td>
<td>通过将中点向黑白方向移动，调整输入的平衡，类似于亮度控制。</td>
</tr>
<tr>
<td><b>对比度：</b></td>
<td>调整输入的对比度。</td>
</tr>
<tr>
<td><b>反转：</b></td>
<td>切换输入颜色的反转。</td>
</tr>
</table>
