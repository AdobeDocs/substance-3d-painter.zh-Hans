# 渐变动态

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![渐变动态图标](./Resources/icon_gradient_dynamic.png "渐变动态")

<b>范围：</b>效果/渐变、灰度、重新映射

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

“渐变动态”滤镜将图像中的灰度值重新映射到由沿渐变放置在特定点的颜色定义的渐变。

在纹理图层上或蒙版内（黑白输出），使用从另一图像取样的渐变来重新映射灰度值。

</td>
</tr>
</table>

## 输入

| 输入名称 | 描述 |
| --- | --- |
| <b>渐变源：</b>颜色 | 使用自定义颜色映射或锚点。 |

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>渐变方向：</b> | 选择是水平还是垂直对渐变源取样。 |
| <b>渐变输入位置：</b> | 调整从渐变输入中取样的位置。 |
