</td>
<td width="100.00%" style="border: 0;" valign="top">

## 描述

直方图扫描滤镜重新映射输入灰度图像的对比度和亮度。

它可以直接用于填充图层，也可以用于蒙版（黑白输出），用于调整对比度和亮度。

</td>
</tr>
</table>

<a name="parameters"></a>

## 参数

| 参数名称 | 描述 |
| --- | --- |
| <b>位置：</b> | 调整直方图位置。 |
| <b>对比度：</b> | 调整结果的对比度/衰减。 |
| <b>反转位置：</b> | 切换位置反转。 在非常高或非常低的“位置”值时，这可有效地反转输出。 |
