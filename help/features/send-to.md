# 发送至

![横幅图像](../assets/sendto_banner.jpg)

<b>发送到</b>是可将资源从项目轻松导出和导入到其他应用程序的操作，无需手动执行。 发送至：可用于将3D模型及其纹理导出到其他渲染应用程序，或从Substance 3D Designer接收Substance素材。

可通过<b>文件>发送</b>至菜单来执行“发送至”操作。

当前支持的<b>发送到</b>为：

* 发送到<b>Photoshop</b>
* 发送到<b>Substance 3D Stager</b>
* 发送到<b>After Effects</b>

Painter还可以从其他应用程序接收资源，例如：

* <b>Substance 3D Designer</b>
* <b>Substance 3D Sampler</b>

有关接收资源的详细信息，请参阅[专用文档页面](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md)。

>[!NOTE]
>
> 由于与Adobe桌面软件存在技术依赖性，因此某些“发送到”工作流程仅适用于Creative Cloud版Painter。
> 
> 此外，如果未安装所需的软件，则“发送到”菜单中的某些操作可能不可用。
