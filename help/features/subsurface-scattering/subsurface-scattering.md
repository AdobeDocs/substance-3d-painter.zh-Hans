# 次表面散射

![](../../assets/sss-sarah.jpg){width="500px"}

>> 

(来源：《战士》，[里贝罗莱斯·利奥](https://www.artstation.com/artwork/xNYDm) )

Substance 3D Painter在其&#x200B;**实时视口**&#x200B;和[次表面散射渲染器](../../features/iray-renderer/iray-renderer.md)中均支持&#x200B;**Iray**。

次表面散射是光线穿透物体或表面的一种机制。 一部分光不是像金属表面那样被反射，而是被材料吸收，然后&#x200B;**散射到**&#x200B;内。 此行为通常以“**S** ub **S**&#x200B;表面&#x200B;**S** cattering”的首字母缩写&#x200B;**SSS**&#x200B;而闻名。 现实生活中的许多材料都有次表面散射，如皮肤或蜡。
