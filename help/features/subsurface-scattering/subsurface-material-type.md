# 次表面材料类型

本页面列出了可使用“次表面散射”功能创建的各种类型的素材，以及如何配置Substance 3D Painter以创建这些素材。 为每种类型的材质指定可在[子曲面参数](subsurface-parameters.md)中设置的比例和颜色。

>[!NOTE]
>
> 此页面列出的值概括了每种类型的材料。 它们不是精确值，必须按项目进行解释和/或调整。

## 人体皮肤

![](../../assets/mat-skin.jpg)

要获得良好的皮肤材质，它需要：

* 良好的基础纹理：对于真实人物，这意味着具有大量的细节和各种颜色。
* 强Height/法向纹理：地下效果将柔化表面细节，首先具有强烈的细节将获得补偿。

| *设置* | *描述* |
| --- | --- |
| **缩放** | <ol data-preserve-html="true"><li data-preserve-html="true">05 - 0.2</li></ol> |
| **颜色** | **R** ： 0.575 **G** ： 0.894 **B** ： 0.376 <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/color-skin.png"/></div> **注意：**&#x200B;此颜色适用于白种人皮肤类型。 |

真实人物的例子可以通过真实人的3D扫描找到：

* 数字艾米莉： <http://gl.ict.usc.edu/Research/DigitalEmily2/>
* 无限现实LPS头： <http://www.ir-ltd.net/> | <http://casual-effects.com/data/>
