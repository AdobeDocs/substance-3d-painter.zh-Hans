# UV 平铺

![](../../assets/banner-uvtiles.jpg)

UV 平铺是一种在纹理集内跨多个纹理范围纹理多组UV的方法。

默认情况下，传统工作流程会在每个UV范围内重复纹理。 使用UV 平铺时，每个范围都变成专用纹理。 此工作流程允许通过将UV拆分为多组纹理来实际提高常规纹理分辨率。 UV 平铺目前仅支持UDIM命名约定。

要了解有关UV 平铺工作流程的更多信息，请参阅以下页面：

* 使用UV 平铺工作流程创建[项目](../../getting-started/project-creation.md)。
* 正在查看[2D 视图](../../interface/viewport/2d-view.md)中的UV 平铺。
* [UV 平铺蒙版](../../interface/layer-stack/geometry-mask.md)以提高性能。
* 导入和使用[图像序列](image-sequence.md)。
* 在[纹理集设置](../../interface/texture-set/texture-set-settings.md)中调整每个UV 平铺的分辨率。

>[!NOTE]
>
> 处理UV 平铺项目可能会要求苛刻，我们建议使用SSD来缩短加载时间并提高整体性能。 我们还建议在SSD上设置缓存位置。
