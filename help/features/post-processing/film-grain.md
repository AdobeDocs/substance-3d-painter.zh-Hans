# 胶片颗粒

![](../../assets/v12_post_grain.jpg)

为图像添加胶片颗粒杂色图案，模拟模拟模拟摄影胶片的有机纹理。

| <b>参数</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金额</b> | 控制颗粒的可见性和强度。 值越高，产生的噪音越显着，越明显。 |
| <b>半径</b> | 设置单个颗粒的大小（以像素为单位）。 较小的值可创建更精细、更细微的颗粒；较大的值可生成更粗糙、更明显的纹理。 |
| <b>类型</b> | 选择单色噪点或彩色噪点。 |

>[!NOTE]
>
> 每次刷新视区时，都会重新生成由此效果生成的噪声。 这就是生成阴影或旋转相机时，噪音可以更新的原因。
