# 色彩校正

![](../../assets/color-correction-example.jpg)![](../../assets/color-correction.png)

颜色校正参数：

| *设置* | *描述* |
| --- | --- |
| **饱和度** | 控制视区中颜色的强度/饱和度。 使用0饱和度获取灰度渲染。 |
| **对比度** | 控制明暗颜色之间的差异。 |
| **亮度** | 控制颜色的亮度/明亮度。 |
| **偏差** | 全局偏移视区的明度。 |
| **深褐色调比率** | 用于为视区提供棕褐色效果的高级参数。 |
| **白平衡色温(K)** | 色温，在开尔文斯。 默认值为6500K，对应于日光。 [参阅维基百科了解更多信息](https://en.wikipedia.org/wiki/Color_temperature)。 |
