# Bloom

![](../../assets/v12_post_bloom.jpg)

在场景的明亮区域周围生成柔和的光晕。 模拟光线在明亮的光晕中散点的方式。

| <b>参数</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金额</b> | 控制开花效果的强度。 值越高，在明亮区域周围产生的光晕越明显。 |
| <b>阈值</b> | 设置触发开花所需的最低亮度级别。 只有比此值亮的像素才会发光。 阈值1.0表示只有比屏幕白色亮的像素才会开花。 |
| <b>衰减</b> | 确定开花与明亮区域的距离。 较低的值可创建更紧凑的发光，而较高的值可将效果扩散到更大的区域。 |
