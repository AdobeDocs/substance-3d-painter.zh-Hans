# 锐化

![](../../assets/v12_post_sharpen.jpg)

增强图像的边缘和精细细节，以提高感知的锐化程度。

| <b>参数</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金额</b> | 控制锐化效果的强度。 值越高，边缘对比度的增加幅度越大。 |
| <b>直径</b> | 设置锐化效果的大小（像素）。 较小的值可锐化精细细节；较大的值影响较宽的边缘，并可创建更明显的效果。 |
