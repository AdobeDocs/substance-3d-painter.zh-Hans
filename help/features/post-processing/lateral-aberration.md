# 横向色差

![](../../assets/v12_post_aberration.jpg)

通过从图像中心向外移动颜色通道，再现真实相机镜头边缘的可见彩色边纹，来模拟色差。

| <b>参数</b> | <b>描述</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>金额</b> | 控制彩色边纹效果的强度。 值越高，朝向边缘的通道分离越明显。 |
| <b>半径</b> | 控制不受影响的中心区域的大小。 较小的值会使色差效果更接近中心，从而影响图像的更多部分。 |
| <b>柔和度</b> | 控制校正的中心和畸变边缘之间的过渡的Smoothness。 |
| <b>比率</b> | 设置受影响区域的长宽比。 输入值1可创建圆形形状；输入值大于1可创建较宽的椭圆图案。 |
| <b>居中X</b> | 象差从其辐射的光学中心的水平位置。 |
| <b>居中Y</b> | 象差从其辐射的光学中心的垂直位置。 |
| <b>消色差像差</b> | 将色差颜色从标准彩虹色调切换为绿/紫色调。 |
