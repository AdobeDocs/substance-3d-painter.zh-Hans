# 插件

Substance 3D Painter具有一个专用的脚本API，允许创建自定义插件以添加自定义功能和行为。\
该增效工具使用Javascript编写，可以与QML语言结合使用，以便在应用程序内创建自定义界面。 有关API中可用内容的更多详细信息，请查看脚本文档（可从应用程序的“帮助”菜单获得）。

## 默认插件

Substance 3D Painter有两个显示不同内容的默认插件。

* [自动存储](autosave.md)
* [资源更新程序](resources-updater.md)
