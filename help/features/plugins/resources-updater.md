# 资源更新程序

![](../../assets/resources-updater-window.png)

**资源更新程序**&#x200B;插件允许浏览当前打开的项目中的资源。\
每个资源都可以由架子中的另一个资源替换。 以红色显示的资源被认为是“过时”的，这意味着同一资源的不同版本存在于架子中，并且（可能）是更新的。
