# 烘焙模式

通过&#x200B;**烘焙模式**，可以访问创建优质、高质量的烘焙所需的所有工具和参数。

要访问&#x200B;**烘焙模式**，请单击视口右上角的（烘焙）羊角面包按钮。 或者，使用[键盘快捷键&#x200B;](../interface/settings/shortcuts.md)**F8**，或选择&#x200B;**模式>烘焙网格映射**

![](../assets/baking/mode_select_buttons.png)

烘焙模式会更改UI布局，并使不同的面板特别适用于烘焙网格图。

## 界面

默认情况下，烘焙模式界面划分为&#x200B;[**视区**](../interface/viewport/viewport.md)&#x200B;和面板区域。

### 视口

[**视区**](../interface/viewport/viewport.md)&#x200B;的行为与&#x200B;**绘画模式**&#x200B;中的行为相同。 您可以使用相同的控件导航，然后使用&#x200B;**频道下拉列表**&#x200B;来更改显示的频道。

**烘焙模式视区**&#x200B;与&#x200B;**绘画模式**&#x200B;有两个不同之处：

* 在视区的左上角，您可以找到&#x200B;[**烘焙可视化设置面板**](baking-visualization-settings.md)。
* 在视区的底部，您可以找到用于&#x200B;**烘焙**&#x200B;当前选定的网格地图的按钮，或返回到&#x200B;**绘画模式**&#x200B;的按钮。

### 烘焙模式面板

有4个面板是烘焙模式独有的：

* [**网格图生成器**](../interface/baking-panels/mesh-map-bakers.md)：选择生成的网格图。
* [**公用设置**](../interface/baking-panels/common-mesh-map-settings.md)：调整所有网格图通用的烘焙设置。
* [**网格映射设置面板**](../interface/baking-panels/mesh-map-settings.md)：调整所选网格映射的烘焙设置。
* [**烘焙日志**](../interface/baking-panels/baking-log.md)：查看烘焙结果并诊断问题。

>[!NOTE]
>
> 有关&#x200B;**常用设置**&#x200B;和&#x200B;**网格映射设置面板**&#x200B;中可用选项的完整列表，请参阅&#x200B;[**网格映射设置**](mesh-map-settings.md)。
