# 网格图设置

<b>网格映射设置面板</b>在烘焙模式下可用，具有用于准备网格以进行烘焙的控件。 要调整给定映射的网格映射设置，请在<b>网格映射烘焙器面板</b>中选择该映射。 每个网格图都可以有不同的可用设置。 “网格映射烘焙器”面板的顶部提供了由所有网格映射共享的<b>常用设置</b>的集合。

在网格图之间共享的任何设置都将显示在通用设置页面上，而不是显示在每个单独的网格图上。

## 常用设置

“公共设置”页面中包含的控件会影响所有网格映射的生成方式。

### 输出设置

| 设置 | Function |
| --- | --- |
| 输出大小 | 定义生成的网格图的X和Y分辨率。 单击锁定可允许非方形分辨率。 |
| 膨胀宽度 | 调整烘焙信息超出UV 岛边界的距离。 |
| 应用漫反射 | 启用此框可将扩散应用于所生成信息的边缘。 |

### 高模参数

| 设置 | Function |
| --- | --- |
| 使用低多边形网格作为高多边形网格 | 启用此设置以根据项目网格生成映射。 |
| High definition meshes | 向项目添加高多边形网格，以便从高多边形网格转换为项目中的低多边形网格。 可以导入多个网格。 |
| 包裹 | 确定如何生成烤架。<ul data-preserve-html="true"> <li data-preserve-html="true">基于距离：使顶点相对于网格膨胀到跨模型的均匀距离，以创建保持架。</li> <li data-preserve-html="true">自动（实验性）：Painter将分析网格并自动生成保持架，尝试在不创建相交的情况下保持保持保持架靠近表面，以获得最佳效果。</li> <li data-preserve-html="true">自定文件：导入已创建用作笼架的文件。 请注意，导入文件的顶点数必须与基础网格的顶点数相同，才能正常工作。</li> </ul> |
| 忽略背面 | 切换是否在烘焙时忽略背面。 这有助于减少伪影，但在某些边缘情况下也会导致错误。 |
| 匹配 | 更改烘焙师确定烘焙时是否包含对象的方式：<ul data-preserve-html="true"> <li data-preserve-html="true">始终：包括在烘焙时命中的笼子内的所有高多边形网格。</li> <li data-preserve-html="true">按网格名称：对于每个轿厢，仅烘焙具有相应网格后缀的网格。</li> </ul> |
| 低多边形网格后缀 | 使用“按网格名称匹配”时，使用此后缀可定义低多边形网格。 |
| 高多边形网格后缀 | 使用“按网格名称匹配”时，使用此后缀可定义高多边形网格，并将它们与相应的低多边形网格匹配。 |
| 消除锯齿 | 调整生成的图中的消除锯齿量。 |

#### 倾斜校正

| 设置 | 描述 |
| --- | --- |
| **绘画倾斜校正** | 进入倾斜校正绘画模式。 |
| **边缘保护** | 切换边缘保护以遮盖靠近硬边缘的绘制倾斜校正值。 |
| **边缘距离** | 控制边缘保护从硬边缘延伸的距离 |
| **边缘对比度** | 控制边缘保护渐变从完全保护到无保护的过渡程度。 |

## ID映射设置

| 设置 | Function |
| --- | --- |
| 颜色来源 | 更改确定ID映射烘焙颜色的方式：<ul data-preserve-html="true"> <li data-preserve-html="true">顶点颜色</li> <li data-preserve-html="true">材质颜色</li> <li data-preserve-html="true">文件 ID</li> <li data-preserve-html="true">网格ID/多边形</li> </ul> |
| 颜色生成器 | 使用“文件ID”或“网格ID/多边形组”作为颜色源时，请确定颜色的生成方式：<ul data-preserve-html="true"> <li data-preserve-html="true">随机</li> <li data-preserve-html="true">色相偏移</li> <li data-preserve-html="true">灰度</li> </ul> |

## 环境遮蔽映射设置

| 设置 | Function |
| --- | --- |
| 次生射线 | 更改次生射线数量。 光线越多，效果越好，但会增加处理时间。 |
| 最小遮挡距离 | 调整光线移动的最小距离以匹配高多边形几何形状并影响生成的AO映射。 |
| 最大遮挡板距离 | 超出此距离而不撞到高多边形网格的光线被认为是未被遮挡的，并且不会影响AO映射。 |
| 相对于边框 | 选中此框后，引用距离的其他设置将基于项目网格的定界框。 1的距离等于定界框的大小 |
| 扩散角度 | 调整生成的光线的angular范围。 较高的扩散角使得曲面更容易被不垂直于曲面的几何形状所遮蔽。 |
| 分布 | 选择光线的分布方式。 |
| 忽略背面 | 更改是否将背面视为遮挡对象。 |
| 自遮蔽 | 选择哪些网格应影响当前网格的环境遮蔽。 |
| 衰减 | 更改通过遮挡距离衰减遮蔽的方式。 |
| 地平面 | 启用此选项可创建用作遮蔽器的地平面。 |
| 地平面偏移 | 更改地平面的位置。 |

## 曲率图设置

| 设置 | Function |
| --- | --- |
| 方法 | 选择如何生成曲率图。 |
| 次生射线 | 调整用于生成曲率图的次生射线数。 更多的次生射线可以产生更好的结果，但会增加处理时间。 |
| 取样半径 | 调整面包师搜索的距离，以计算当前点的曲率。 |
| 相对于定界框 | 选中此选项后，所有距离都将基于网格定界框的大小。 |
| 自相交 | 选择在确定曲率时要考虑的对象。 |
| 自动色调映射（按 UV 平铺） | 选中此项可根据UV磁贴自动调整色调图曲率图。 |
| 色调映射最小值 | 如果禁用自动色调映射，请调整色调映射的最小值。 |
| 色调映射最大值 | 如果禁用自动色调映射，请调整色调映射的最大值。 |

## 位置映射设置

| 设置 | Function |
| --- | --- |
| 模式 | 选择是生成所有轴位置映射，还是只计算选定轴的位置。 |
| 轴 | 如果选择了“单轴”模式，请使用此设置选择要计算的轴。 |
| 标准化类型 | 更改使用“定界框”、“定界球”或禁用规范化的位置值的规范化方式。 |
| 标准化比例 | 更改位置空间的最大边界。 |

| 设置 | Function |
| --- | --- |

| 最大遮挡距离 | 超出此距离而不撞到高多边形网格的光线被认为是未被遮挡的，并且不会影响Thickness图。 |
| 相对于边框 | 选中此框后，引用距离的其他设置将基于项目网格的定界框。 1的距离等于定界框的大小 |
| 扩散角度 | 调整生成的光线的angular范围。 较高的扩散角使得曲面更容易被不垂直于曲面的几何形状所遮蔽。 |
| 分布 | 选择光线的分布方式。 |
| 自遮蔽 | 选择哪些网格应该影响当前网格的Thickness。 |
| 标准化 | 更改Thickness值的规范化方式。 |

## Height映射设置

| 设置 | Function |
| --- | --- |
| 标准化 | 更改Height值的规范化方式。 |
| 缩放除数 | 如果“规范化”设置为“手动”，请使用此滑块调整缩放因子并调整Height映射规范化。 |
