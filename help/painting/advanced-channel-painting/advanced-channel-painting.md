# 高级通道绘画

可以对着色器中使用的几个默认通道进行绘制，以创建高级或复杂效果。 例如，绘制转换为法线图的Height信息。

当前可用的通道：

* [ambient occlusion绘画](ambient-occlusion-painting.md)
* [流程图绘画](flow-map-painting.md)
* [高度图绘画](height-map-painting.md)
* [法线图绘画](normal-map-painting.md)
