# Photoshop画笔参数兼容性

此页面列出了所有Photoshop画笔参数及其与Substance 3D Painter画笔引擎的兼容性。

## 一般兼容性

查看ABR文件时，Substance 3D Painter将仅检索特定的画笔/工具预设：

| *预设类型* | *支持* | *描述* |
| --- | --- | --- |
| **画笔（位图）** | 已导入 | 将导入基于位图的画笔预设，如同位图图一样。 |
| **画笔（程序）** | 已忽略 | 不会导入基于程序形状（如圆形）的画笔预设。 |
| **画笔（喷枪）** | 已忽略 | 带有喷枪设置的画笔预设不会导入。 |
| **画笔（毛刷）** | 已忽略 | 带有毛刷设置的画笔预设不会导入。 |
| **画笔（可蚀除）** | 已忽略 | 具有侵蚀设置的画笔预设不会被导入。 |
| **铅笔** | 已忽略 | 不导入铅笔预设。 |
| **混合器画笔** | 已忽略 | 混合器画笔预设不会导入。 |
| **仿制图章** | 已忽略 | 仿制图章预设不会导入。 |
| **涂抹** | 已忽略 | 不导入涂抹预设。 |

## 参数

要详细了解这些参数的功能，请参阅官方[Photoshop文档](https://helpx.adobe.com/photoshop/using/creating-modifying-brushes.html) 。

并非支持所有Photoshop画笔参数。 请参阅图例，了解下面所述的每个参数的状态：

* **方形(■)** ：表示支持该参数，请参阅描述以了解如何访问它。
* **叉号(✖)** ：表示不支持该参数。

>[!NOTE]
