# 安装粒子编辑器

要创建和编辑粒子系统行为，需要使用PopcornFX编辑器。\
从以下链接之一下载编辑器： [镜像1](http://downloads.popcornfx.com/updates/1.5.5.20787/PopcornFx-Editor_Setup_v1.5.5.20787.exe)，[镜像2](https://www.dropbox.com/s/z1vwzvk2ywlug4p/PopcornFx-Editor_Setup_v1.5.5.20787.exe?dl=1)。

>[!NOTE]
>
> Painter使用旧版本的编辑器，因为它需要特定版本的支持。 有关详细信息，请参阅[官方维客](https://wiki.popcornfx.com/)。
