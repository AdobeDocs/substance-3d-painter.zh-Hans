# 创建粒子预设

允许绘制粒子的粒子系统使用&#x200B;**PopcornFX**，它依赖于&#x200B;**.pkfx**&#x200B;文件来定义行为。

粒子笔刷由两部分组成： **发射器**&#x200B;和接收器&#x200B;**3&rbrace;，它们一起保存在预设中。**&#x200B;应用程序加载发射器并覆盖冲突事件，以便在绘画时发射接收器。
