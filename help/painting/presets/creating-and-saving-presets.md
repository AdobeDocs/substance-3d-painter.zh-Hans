# 创建和存储预设

使用[属性窗口](../../interface/properties.md)调整画笔参数，然后将画笔配置存储为预设，以便将来快速重复使用。

>[!NOTE]
>
> 在配备了[路径工具](../tool-list/path.md)后，[属性面板](../../interface/properties.md)中提供了“预设”部分，您可以在其中快速访问与路径相关的预设。 您还可以将路径预设添加到收藏夹。 在此处了解有关管理您最喜爱的[路径预设](../tool-list/path.md)的更多信息。

## 创建新预设

![](../../assets/save-preset-1.png)

当工具属性可用（绘画图层或绘画效果）时，可在“属性”窗口中右键单击以创建预设。

在“属性”窗口中右键单击以打开包含以下选项的上下文菜单：

* <b>创建工具预设</b> ：将画笔参数和材质与所有必需的资源保存在同一预设文件中。
* <b>创建素材预设</b> ：仅将素材属性和素材资源保存在预设文件中。
* <b>创建画笔预设</b> ：仅在预设文件中保存画笔参数以及Alpha和模板资源。

## 更新现有预设

![](../../assets/update-preset.png)

您可以根据“属性”窗口中的当前值更新现有预设。 在[资源](../../interface/assets/assets.md)窗口中右键单击资源，然后选择“从当前工具更新”以更新预设。
