# 快速蒙版

快速蒙版使您可以遮盖不想绘画的网格部分。

* 按&#x200B;**Y**&#x200B;以切换到快速蒙版编辑模式，这将允许您绘画临时蒙版。
* 再次点击&#x200B;**U**&#x200B;可切换回上一个工具并在该蒙版上绘画。
* 按&#x200B;**Y**&#x200B;以重置/禁用蒙版。
* 在快速蒙版编辑模式下按&#x200B;**I**&#x200B;以反转蒙版。
