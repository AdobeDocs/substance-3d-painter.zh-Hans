# 投影

![](../../assets/image2015-3-19-17-56-54.png){width="50px"}

该投影是一种工具，允许通过将材料投影到屏幕/视口空间来设置其绘画。 它与模板共享类似的控制。

可以通过按&#x200B;**快捷键S**&#x200B;来编辑投影变换：

* 使用&#x200B;**S +鼠标左键**&#x200B;旋转模板。
* 使用&#x200B;**S +鼠标左键单击+ SHIFT**&#x200B;可捕捉/限制模板旋转。
* 使用&#x200B;**S +鼠标右键单击**&#x200B;可缩放/取消缩放模板。
* 使用&#x200B;**S +鼠标中键**&#x200B;单击模板。
