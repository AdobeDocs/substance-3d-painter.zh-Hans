# 填充路径

![](../../assets/banner_filled_path.jpg)

填充路径工具是一种路径工具，用于在填充统一颜色的3D模型表面创建形状。

![](../../assets/filled_path_across_gaps.png)

可从“路径工具”菜单访问<b>填充路径</b>工具：

![](../../assets/filled_path_menu.png)

## 设置

路径填充设置包括：

| 设置 | 描述 |
| --- | --- |
| 不透明度 | 控制填充形状的最终不透明度。 |
