# 涂抹工具

![](../../assets/image2018-6-12-18-14-12.png)

在Substance 3D Painter 2中引入的涂抹工具与[绘画工具](https://support.allegorithmic.com/documentation/display/SPDOC/Paint+brush)共享相同类型的参数。

![](../../assets/smudge.gif)

## 使用情况

使用涂抹工具最简单的方法是，作为常规绘画工具直接在绘画图层的内容上使用它。

使用涂抹工具的一种更智能的方法是创建绘画图层，并将图层的所有通道都设置为“穿透”混合模式。 这将允许以非破坏性方式涂抹位于“涂抹图层”下方的所有图层。 下面的图层将保持不变，涂抹图层将考虑稍后应用的所有修改。
