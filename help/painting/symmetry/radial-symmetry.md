# 径向对称

径向对称围绕轴径向复制描边或填充图层内容：

![](../../assets/radial-demo.gif)

## 使用机械手定位对称轴

您可以通过3D视图顶部“上下文”工具栏中的<b>“对称设置”按钮</b>访问“对称”显示设置。 在显示设置下，可以启用和自定义操纵器。 在3D视图中拖动操纵器手柄以更改对称轴的位置。

![在视窗中可以看到操纵器的“径向对称设置”面板的屏幕截图。](../../assets/RadialSymmetryManip.png){width="600px"}

## 径向对称参数

![属性面板的“对称”部分的屏幕截图](../../assets/FillSymmetry_1.png){width="300px"}

| *参数* | *描述* |
| --- | --- |
| <b>轴</b> | 定义用于执行对称的场景轴。 |
| <b>翻转副本</b> | 在U或V轴上翻转交替副本。 对具有文本等方向的内容使用对称时，这会很有帮助。 |
| <b>轴位置：X、Y、Z</b> | 定义轴在项目中的偏移量。 可以使用滑块或操纵器编辑此值（见上文）。 |
| <b>显示轴</b> | 如果启用，表示对称轴的视口中将显示一条透明线。 |
| <b>显示交集</b> | 如果启用，将在视区的网格上绘制一个点，以显示对称轴与网格相交的位置。 |
| <b>显示光标（画笔工具）</b> | 如果启用，将在对称的另一侧显示第二个光标，以指示何时执行绘画。 |
| <b>绘画时隐藏（画笔工具）</b> | 如果启用，则在绘画过程中将隐藏第二个光标（直到松开鼠标单击）。 |
| <b>显示轴位置操纵器</b> | 切换视区中操纵器的可见性。 |
| <b>操纵器大小</b> | 控制视区中操纵器的大小。 |
