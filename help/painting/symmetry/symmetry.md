# 对称

![](../../assets/radial-demo.gif)

“对称”是一个很有用的设置，您可以在画笔和填充图层上使用，以便根据几何约束轻松准确地复制：

* 通过画笔图层，使用对称功能根据对称轴在网格的其他位置复制单个画笔描边。
* 对于填充图层，使用对称围绕对称轴复制整个填充图层。

详细了解您可以在Painter中使用的对称类型：

* [Mirror Symmetry](mirror-symmetry.md)
* [径向对称](radial-symmetry.md)

## 使用对称工具

您可以使用上下文工具栏中的<b>对称按钮</b>启用对称。

![](../../assets/SymmetryToggle.png)

使用上下文工具栏中的<b>对称设置按钮</b>调整对称选项。

![](../../assets/BrushSymmetrySettings.png)

>[!NOTE]
>
> 2D 视图中的绘画投影和模板投影不支持对称。 我们建议根据需要使用3D视图。

## 对填充图层使用对称

选择填充图层后，您可以使用上下文工具栏中的<b>对称按钮</b>，就像使用画笔工具对称一样。 使用填充图层，您还可以从<b>对称面板</b>启用和访问属性选项。 对称仅适用于以下投影方法：

<table>
<tr style="border: 0;">
<td style="border: 0;" valign="top">

* 三投影
* 投影
* 球体投影
* 圆柱投影
* 变形投影

选择符合条件的投影方法后，可在“属性”面板的“对称”部分启用“对称”以访问对称选项。

如果选择了不支持的投影方法，则<b>启用对称</b>选项将不可用，并且上下文工具栏中的<b>对称按钮</b>将灰显。

</td>
<td style="border: 0;" valign="top">

![属性面板的“对称”部分的屏幕截图](../../assets/FillSymmetry.png){width="400px"}

</td>
</tr>
</table>

>[!NOTE]
>
> 对称显示选项仅通过上下文工具栏中的<b>对称设置按钮</b>可用。 无法从<b>“对称”面板</b>中修改属性显示设置。
