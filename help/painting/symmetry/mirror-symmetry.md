# Mirror Symmetry

镜像对称是基于轴的对称，可以在上下文工具栏中启用：

![](../../assets/symmetry-mirror.png)

## 使用操纵器定位对称轴

您可以通过3D视图顶部“上下文”工具栏中的<b>对称设置按钮</b>访问对称显示设置。 在显示设置下，可以启用和自定义操纵器。 在3D视图中拖动操纵器手柄以更改对称轴的位置。

![](../../assets/MirrorSymmetryManip.png)

## 镜像对称参数

![镜像对称设置的屏幕截图](../../assets/MirrorSymmetry-2.png){width="300px"}

| *参数* | *描述* |
| --- | --- |
| <b>轴</b> | 定义用于执行对称的场景轴。 |
| <b>轴位置</b> | 在项目中定义轴的偏移量。 可以使用滑块或操纵器编辑此值（请参阅上文）。 |
| <b>显示平面</b> | 如果启用，透明平面将在视口中可见，以分隔镜像对称的每一侧。 |
| <b>显示交集</b> | 如果启用，将在视口中的网格上绘制一条线来分隔镜像对称的每侧。 |
| <b>显示光标</b> | 如果启用，第二个光标将显示在对称的另一侧，以指示何时执行绘画。 |
| <b>绘画时隐藏</b> | 如果启用，则在绘画过程中将隐藏第二个光标（直到松开鼠标单击）。 |
| <b>操纵器大小</b> | 控制视口中操纵器的大小。 |
